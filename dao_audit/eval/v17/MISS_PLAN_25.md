## 各项根因与处理办法

1. **bancor_network · `TokenHandler.safeTransferFrom`**（NO_RULE）— 根因：transferFrom is issued as a low-level call with an encoded selector (execute(token, abi.encodeWithSelector(...))); arbitrary-send-erc20 only matches high-level transferFrom calls; no detector flags a public asset helper that should be internal；模式：public helper issuing transferFrom via encoded low-level call。处理：evaluate a mature external static-analysis ruleset for the specific pattern on the dev item; accept only if it fires on the vulnerable item AND is silent on the fixed version and on the secure controls; otherwise keep NOT_COVERED and add the pattern to the manual checklist。
2. **bancor_network · `TokenHandler.safeTransfer`**（NO_RULE）— 根因：same encoded low-level call; no detector for a public helper moving the contract's own tokens；模式：public helper moving the contract's own tokens。处理：evaluate a mature external static-analysis ruleset for the specific pattern on the dev item; accept only if it fires on the vulnerable item AND is silent on the fixed version and on the secure controls; otherwise keep NOT_COVERED and add the pattern to the manual checklist。
3. **bancor_network · `TokenHandler.safeApprove`**（NO_RULE）— 根因：same encoded low-level call; no detector for public approve helpers；模式：public helper setting allowances of the contract's tokens。处理：evaluate a mature external static-analysis ruleset for the specific pattern on the dev item; accept only if it fires on the vulnerable item AND is silent on the fixed version and on the secure controls; otherwise keep NOT_COVERED and add the pattern to the manual checklist。
4. **bond_fixed_expiry_teller · `BondFixedExpiryTeller.redeem`**（PARSE_FAIL）— 根因：vulnerable commit has no recorded submodules/lockfile for solmate and clones-with-immutable-args; dependency versions unknown -> ANALYSIS_INCOMPLETE (still after V0.16 toolchain fixes)。处理：toolchain fix + regression; dependencies must be verifiable from the repository at the commit, never guessed; afterwards re-classify the item by what the analysis then shows。
