# G0 / G1 前置可行性验证报告 — 经济安全性质验证工具链

授权范围:仅自有 ERC-4626 测试合约 + 公开参考实现 + 本地隔离 EVM。无真实钱包、无资金转移、无未授权线上合约。
不修改历史成绩;V0.12–V0.18、MS0 归档不动。原始日志见 `econsec2/g0/results/`、`econsec2/g0/test/`、`econsec2/g0/src/`。

## 执行环境与来源
- 编译器:solc **0.8.28+commit.7893614a**(vendored);Foundry **1.5.1**;halmos **0.3.3** / z3 **4.12.6**;Slither 0.11.6。
- 正向参考实现:**OpenZeppelin Contracts 4.9.6** `ERC4626`(公开参考,未改)。
- 教学缺陷合约:**自有**(`src/Vaults.sol` `BuggyTeachingVault`),单一、公开注明的会计缺陷(赎回时对资产按 +1% 多计,
  违反 ERC-4626"付给用户的资产向下取整")。其缺陷已知且写明,**不作为未知漏洞发现**。

## 三项性质(各附规范来源)
1. **P1 份额会计一致性**:份额 totalSupply == 所有持有者份额余额之和(来源:ERC-20 供应定义;ERC-4626 份额即 ERC-20)。
   **不**假设 totalAssets 等于代币余额——P1 完全不引用资产代币余额。
2. **P2 合法存取 + 往返不获利**:存入 x、立即赎回所得份额,返还资产 ≤ x(来源:ERC-4626 安全要求 + 购买力守恒);
   另含"合法存款不被误拒"。
3. **P3 资产转换与舍入边界**:convertToAssets(convertToShares(a)) ≤ a,且转换单调(来源:ERC-4626 舍入规则,付给用户向下取整)。

**BLOCKED 记录**:本轮无 BLOCKED。关键发现——此前各阶段被安全检查阻止的是"自动构造攻击序列";
而本轮"标准属性工具在授权自有合约上产生反例"这一形式**正常执行、未被阻止**(Foundry 与 halmos 均对教学缺陷版给出可复现反例)。
这正是 Phase-1 设计中列为阻塞性前置条件 R1/G0 的问题,现**得到肯定回答**。

## G0 结论:工具链具备性质验证能力(肯定)
- Foundry 能:对参考版正向验证全部性质并确认不误拒合法操作;对教学缺陷版给出 P2、P3 的**可复现反例**;P1 在两者皆成立(无误报)。
- halmos 能独立对教学缺陷版给出符号反例;但对参考版的安全性证明超时(**INCONCLUSIVE**,如实记录,未标 PASS)。
- Slither 可用于事实提取(非性质验证工具,本轮未跑)。
- 严格区分已落实:参考版性质成立 = 正向验证;教学缺陷版被发现 = 工具对**已知自写缺陷**的检出,**不等于未知漏洞发现**。

## 是否值得进入 G1 / 下一阶段
**值得(GO 到下一阶段设计)**,理由:G0 的唯一命题"工具链能做性质验证并在授权自有合约上产生可复核反例"已由真实执行证明,
且阻塞性前置 R1 被解除。但须明确边界:
- G0 只证明**工具能力**与**反例可执行性**;**未**证明系统能在**未知**合约上发现违例——那是下一阶段独立盲测要回答的,G0 不得替代。
- halmos 在金库形态上更像缺陷发现器而非证明器(安全版超时);下一阶段以 **Foundry 不变量/模糊为主、halmos 作辅助反例**,不依赖 halmos 证明安全。

## 下一阶段(G2)独立盲测设计
- **样本**:仅公开披露且已修复的 ERC-4626 金库历史实现 + 独立安全对照;每漏洞版配公开修复版;授权/公开源码,隔离本地 EVM。
  与 round1–4、MS0、G0 零项目重叠。规模 ≥8 漏洞版、≥4 安全对照,不足则如实标探索性。
- **冻结(测试前)**:性质模板(由 Claude 依规范生成)、Foundry/halmos 编译规则、评分标准、工具版本 SHA256(复用 `freeze_engine.py`)。
- **标签隔离**:漏洞位置/类别/修复 diff 不进入待测输入;复用 `check_isolation.py` 静态 + 运行时文件访问审计,验证进程只读合约源码。
- **流程**:Claude 看合约(无答案)提候选性质 → 编译为 Foundry/halmos 检查 → 运行 → REFUTED/SUSPECTED/INCONCLUSIVE,
  CONFIRMED 仅独立人工复核在反例上确认;人工层不计入自动检出率。
- **独立评分(Wilson 95%CI,分开)**:真实缺陷召回、精确率、安全/修复版误报率、修复版区分率、不可分析率;
  关键新指标——**性质是否由 Claude 在不见答案时提出**(区分"发现"与"复现已知")。
- **GO/NO-GO 门槛(先于样本冻结,不降阈不事后调参)**:自动 REFUTED→独立 CONFIRMED 的真实缺陷召回 ≥0.50(CI 下界 ≥0.30)、
  精确率 ≥0.50、安全/修复误报率 ≤0.20、修复版区分率 ≥0.50、不可分析率 ≤0.10;任一未达 → NO-GO,维持辅助审计定位。
