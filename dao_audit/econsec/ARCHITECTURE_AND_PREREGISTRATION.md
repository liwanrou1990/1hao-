分支 `claude/econsec-research`（自 `claude/v018-dev` @ 0c2b7e3）。V0.12–V0.18 代码、冻结记录
（`eval/engine_freeze.json`、`eval/v17/engine_freeze_v17.json`、`results/round4/engine_freeze_round4.json`）
与 Round 1–4 结果不改、不重评分。本文件在任何测试运行前写定。

## 0. 研究问题
在没有漏洞标签、位置、攻击路径的情况下，系统能否从授权审计的协议代码中发现**未被预先编码**的安全性质违例？
“未被预先编码”指：性质由系统从协议结构生成（而非为某个已知漏洞手写），且在独立未知样本上验证。

## 2. 模块架构（自动化只产生候选风险与证据）
```
[M1 构建] 项目快照 → 精确编译 → Slither IR                (复用 compiler/*)
[M2 经济模型] 事实提取：资产持有(余额/ERC20 引用)、份额(totalSupply/份额映射)、
             债务/抵押(按地址索引的数值映射及其在 require 中的比较)、权限(入口的 msg.sender 条件事实)、
             结算(写状态并转移资产的函数)、外部依赖(高层调用目标)         (复用 perm/deps + evidence)
[M3 性质生成] 从模型实例化候选性质模板，每条带：业务假设、合法例外、证据来源、角色集合
             模板族：资产守恒 / 抵押偿付 / 份额估值一致 / 结算唯一性 / 权限有效性 / 跨合约状态一致
[M4 检查] 生成 Foundry 不变量 handler + 性质断言；halmos 对可符号化性质做有界检查；
          同时生成“正常业务序列”测试，验证性质不误拒合法操作
[M5 判定] REFUTED(反例可复现且不属合法例外) / SUSPECTED(反例但假设或例外未排除) /
          INCONCLUSIVE(不可达、超时、构建或工具失败) / CONFIRMED 仅由人工复核在隔离证据上确认
[M6 评估] 预注册 → 冻结(M2–M5 代码 SHA256 + 工具版本 + 参数) → 独立未知样本 → 独立评分
```
“性质违例 = REFUTED”，是自动层的最高输出；CONFIRMED 永远需要人工复核（高危必须）。

## 3. 里程碑
| 里程碑 | 内容 | 验收 |
|--------|------|------|
| MS0（本次） | 复用评估、架构、预注册；M2/M3 原型；M4 在自有靶标上的首批隔离结果 | 文档入库；≥1 个自有靶标产生可复现 REFUTED，且修复版上同一性质通过，正常业务不被误拒 |

| MS2 | 冻结 + 独立未知样本（全新项目，带独立安全对照与修复版；策展人不接触引擎） | 按 §5 标准 |
| MS3 | 结论：继续/终止 | §5 未达标 → 终止自动发现方向 |

## 4. 边界（硬性）
只用自有或明确授权的合约与隔离本地 EVM；不接真实钱包，不发资金交易，不对未授权生产合约做主动验证；
历史案例只作开发/验证/盲测输入，标签与修复差异不进入待测输入（沿用 `check_isolation.py` 运行时审计）；
工具报错、不可达、不完整代码一律 INCONCLUSIVE；授权范围内的真实发现走保密报告与负责任披露，不以未公开漏洞获利。

## 5. MS2 验收标准（先于任何未知样本写定；不降阈、不事后调参、不复用开发集）
独立未知样本 ≥10 个漏洞版（公开披露、含源码与修复）、≥5 个安全对照、每个有修复的漏洞版配修复版；
按项目划分，与 round1–4 零项目重叠；策展人不读取 M2–M5 代码。
- **召回**：漏洞版上自动层 REFUTED 命中标注位置（同合约且函数匹配或行 ±5）的比例 ≥0.50（Wilson CI 下界 ≥0.30）；
- **精确率**（REFUTED 中命中标注的比例）≥0.50；
- **误报率**：安全对照 + 修复版中出现 REFUTED 的样本比例 ≤0.20；
- **修复版区分率**：漏洞版 REFUTED 且修复版同一性质通过 ≥0.50 的配对；
- **不可分析率** ≤0.10，逐案列出；
- **完整经济影响链识别率**：链式案例中“性质违例 + 资产流出路径”都被自动层给出 ≥0.50。
任何一项未达 → **不得宣称能提前发现真实漏洞**，建议终止该方向。
