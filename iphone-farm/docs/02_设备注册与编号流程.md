# 02 设备注册与编号流程

目的：让“编号 N”在整个系统里唯一且稳定地对应一台物理 iPhone，使每个动作的目标可追溯、可核对（目标 7）。

## 1. 三重身份 + 蓝牙 host

| 身份 | 来源 | 用途 |
|---|---|---|
| `capture_id` | iPhone-use `/devices[].id`（AVFoundation uniqueID） | **所有动作的 `device` 参数**，必须完整，不允许前缀/名称 |
| `name` | 手机“关于本机 → 名称”，必须为 `IF01`…`IF30` | 人眼可读的编号来源；注册时与编号一致才允许绑定；运行时漂移则拒绝动作 |
| `udid` | `system_profiler SPUSBDataType -json` 的 `serial_num` 或 `idevice_id -l` / `pymobiledevice3 usbmux list`（6s/7/8 的 USB 序列号即 40 位 UDID） | 与 iPhone-use 无关的独立证据，防止两个“IF07” |
| `ble_host` | `/status.bluetoothHosts[].host`（CBCentral UUID），由 `screen.id == capture_id` 反查 | 一个 host 只能绑一台；动作前核对 `pointer.host`，防交叉绑定 |
| `usb_location_id` | `system_profiler` 的 `location_id` | 对应 A-832 的物理口，便于排障（“第 3 排第 2 口”） |

注册表 `state/registry.json`（gitignore），结构：
```json
{"version":1,"devices":[{"slot":7,"capture_id":"…完整…","name":"IF07","udid":"…40hex…",
  "usb_location_id":"0x14230000 / 3","ble_host":"5E2B…","registered_at":…,"last_verified_at":…}]}
```

## 2. 流程（推荐“逐台插入法”）
1. 每台手机先改名 `IFxx`、开 AssistiveTouch、自动锁定=永不（docs/01 §3）。
2. 插入第 N 台 → 信任 → AssistiveTouch 蓝牙连接 “iPhone Use” → 等 `/status` 中出现 `pointer.ready=true`。
3. 运行：
   ```bash
   ifarm register --slot N        # 只注册名称为 IFN 的那台；无 --slot 则注册所有符合 IFxx 的在线设备
   ```
   注册器会：
   - 在 `/devices` 找 `name == IFxx`，取其完整 `capture_id`；
   - 取 UDID：若 `capture_id` 本身是 40 位十六进制则直接用；否则在 `system_profiler` 中找同名 iPhone 的 `serial_num`，并要求它出现在 `idevice_id -l` 列表中；取不到 UDID 默认**拒绝注册**（`--no-udid` 可跳过，不推荐）；
   - 校验：名称编号 == 目标编号；该 `capture_id`/UDID 未被其他编号占用；
   - 记录当时的 `pointer.host` 为 `ble_host`（若尚未配对，稍后 `ifarm verify --bind-hosts` 补写）。
4. 重复到 30 台。每级（5/10/15/20/30）注册完立即 `ifarm verify`。
5. 在 A-832 每个口贴标签 `IFxx`，与 `usb_location_id` 对应，之后固定不换口。

## 3. 运行时核对（每个动作自动执行）
`single.py:verify_identity`：
1. 设备在 `/status` 中存在（否则 USB 未识别/画面未建立）；
2. `name` 仍等于注册名（否则“名称漂移”，拒绝；`--allow-name-drift` 可放行）；
3. 若注册了 `ble_host` 且当前 `pointer.host` 非空，二者必须相等（否则“host 漂移/交叉绑定”，拒绝）；
4. 请求 `device` = 完整 `capture_id`；响应 `device`/截图头 `X-Device` 必须回显同一值（`client.py` 强制，前缀调用会被判定目标不一致）。

## 4. 变更与注销
- 换手机、换 SIM、重装系统：`ifarm unregister N` 后重新 `ifarm register --slot N`（注销与注册都写入事件日志）。
- 蓝牙重新配对后 host 变化：`ifarm verify` 会报 `host_ok=false`；确认是同一台手机后，手工把 `ble_host` 改为新值（或删除该字段后 `verify --bind-hosts`）。
- 不要复用编号给另一台物理手机；需要时启用新编号（31+）并更新 `config/groups.yaml`。

## 5. 命令速查
```bash
ifarm devices                    # 在线设备 + 已注册编号
ifarm register [--slot N] [--udid X] [--no-udid]
ifarm unregister N
ifarm verify [--bind-hosts]      # 名称/host/在线/可控核对，退出码 2 表示有不一致
ifarm events --kind register     # 注册历史
```
