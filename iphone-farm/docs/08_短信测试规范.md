# 08 短信测试规范

1. **范围**：只在本项目自有测试设备（注册表内 30 台、各自 SIM）与 `config/sms_policy.yaml` 登记的授权联系人之间收发短信。联系人登记必须含授权人、授权日期。
2. **单机**：短信类动作（`sms_open` 及任何在“信息”App 内的点击/输入）只允许 `ifarm run <编号> …` 单机执行；`broadcast.py` 对 `sms_*` 硬性拒绝（退出码 3）。
3. **人工确认**：程序只记录“已在编号 N 上执行了打开信息/输入/点击发送”这一动作事件；**送达与否必须由人工在收件设备上确认**后，在事件日志中追加 `kind=sms_confirm` 记录（`ifarm events` 可查）。在确认前，任何短信结果一律 `UNVERIFIED`。
4. **禁止**：把模拟服务器（`--simulated` / `SIMULATED_MOCK`）或 dry-run 的结果报告为真实 SMS 成功；向非授权号码发送；批量群发。
5. **暂不开发**短信聚合工作台（读取/汇总各机短信）；如后续需要，另行评估（iPhone-use 无读取短信的接口，只能靠截图 + OCR 或 WDA 的 accessibility 树）。
6. 测试内容建议只用固定文本（如 `IF07 test 2026-11-02 14:05`），便于人工比对。
