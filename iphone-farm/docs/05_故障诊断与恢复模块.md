# 05 故障诊断与恢复模块（`monitor.py` / `ifarm monitor`，第三阶段）

## 1. 状态机（每台已注册设备）
| 状态 | 判定（来自 `/status`） | 典型原因 |
|---|---|---|
| `USB_ABSENT` | 设备不在列表 | 线松/拔出、未信任、Hub 掉电、iPhone-use 捕获未建立 |
| `NO_FRAME` | `lockState` 为 paused/noFrame | 手机息屏/卡死、USB 带宽不足 |
| `BLE_UNPAIRED` | `bluetooth=false` | AssistiveTouch 蓝牙未连/掉线 |
| `BLE_UNMATCHED` | `bluetoothState=unmatched` | 蓝牙连上但未与该屏匹配（host 在 `unmatchedHosts`） |
| `HOST_DRIFT` | `pointer.host != 注册 ble_host` | 交叉绑定、重新配对 |
| `POINTER_NOT_READY` | `pointer.ready=false` | 校准中/订阅未完成 |
| `LOCKED` | `lockState` 为 locked | 手机锁屏（OCR 启发式，仅提示） |
| `OK` | 其余 | |

## 2. 记录
- 所有状态变化写 `state/events.jsonl`（`kind=state`），非 OK 状态同时写 `kind=error`；超过阈值的 USB_ABSENT/NO_FRAME 写 `alert=true`。
- `ifarm events --kind error --tail 200` 查看；`ifarm monitor` 结束时打印每台 `transitions / ble_drops / recoveries / last_error`。
- `ble_drops`：从 OK 跌到蓝牙类异常的次数，作为逐级测试“蓝牙稳定性”指标。

## 3. 自动恢复（`farm.yaml monitor.recovery`）
| 状态 | 动作 | 开关 |
|---|---|---|
| `BLE_UNMATCHED` / `HOST_DRIFT` 且注册 host 在 `unmatchedHosts` | `POST /pair {device, host}` | `enable_pair` |
| `BLE_UNMATCHED` / `HOST_DRIFT` 其他情况 | `POST /match {force:true, probe:true}` | `enable_match` |
| `POINTER_NOT_READY` 持续 >10s | `POST /calibration/auto {device}` | `enable_calibration` |
| `USB_ABSENT` > 60s / `NO_FRAME` > 15s | 告警（需人工：线缆/信任/解锁） | 阈值可调 |
| 以上均无效 | 重启 iPhoneUse.app（**中断全部设备**） | `enable_app_restart`（默认关） |
每台 10 分钟内最多 `max_recovery_attempts_per_10min`（默认 3）次恢复，避免风暴；恢复在设备锁内执行，不与广播冲突。
`BLE_UNPAIRED` 无法自动恢复（需要在手机 AssistiveTouch 里重新连接），只告警。

## 4. 使用
```bash
ifarm monitor                         # 持续运行，每 3s 轮询，打印 1:OK 2:OK 3:BLE_UNPAIRED …
ifarm monitor --duration 600 --quiet  # 10 分钟观察后输出汇总（逐级测试用）
ifarm monitor --no-recover            # 只观察不恢复
```

## 5. 任务互斥（`locks.py`）
- 每台设备一把 `threading.Lock` + `state/locks/device-<hash>.lock` 文件锁（`flock`）。
- 单机动作、广播中的每台、监控恢复都要先拿锁；跨进程同样互斥。
- 锁文件记录持有者与时间，便于排查“谁在占用编号 7”。

## 6. 人工排障清单
1. `./scripts/preflight_mac.sh`：USB 树、`idevice_id -l`、蓝牙控制器、`/status`。
2. `ifarm devices` 与 `ifarm verify`：找出名称/host 不一致。
3. 蓝牙问题先看 iPhone-use 的 `./scripts/diagnose-bluetooth.sh 5`（源码目录），再重启 iPhoneUse，等 “advertising as iPhone Use” 后在手机端重连。
4. 画面 paused：检查手机是否息屏、换口/换线、减少同时在线台数验证是否带宽问题。
