# 03 单机控制模块（`single.py` / `ifarm run`）

## 1. 能力
| 动作 | 说明 | 示例 |
|---|---|---|
| `tap` | 点击（默认 0–1 相对坐标；`fraction:false` 为像素） | `ifarm run 1 tap --x 0.5 --y 0.5` |
| `swipe` | 多点滑动，`duration` 默认 0.3s | `ifarm run 1 swipe --params '{"points":[{"x":0.5,"y":0.8},{"x":0.5,"y":0.3}]}'` |
| `swipe_up` | 从下往上滑 | `ifarm run 1 swipe_up` |
| `type` | 键盘输入（仅 ASCII） | `ifarm run 1 type --text "hello"` |
| `key` | 按键 + 修饰键 | `ifarm run 1 key --key space --params '{"modifiers":["cmd"]}'` |
| `home` / `wake` | 回主屏 / 唤醒（不解锁） | `ifarm run 1 home` |
| `open_app` / `open_settings` | Home → Spotlight → 输入名称 → 回车 | `ifarm run 1 open_app --query Settings` |
| `power` | 电源键短按（非幂等，禁止广播） | `ifarm run 1 power` |
| `sms_open` | 打开原生“信息”App（单机专用，禁止广播，见 docs/08） | `ifarm run 1 sms_open` |
| 截图 | `ifarm screenshot 1 [--out 路径]`，记录延迟与 `X-Device` |

设备引用：编号 `1`、`IF01`，或完整 `capture_id`；**不接受前缀**。

## 2. 执行流程
```
resolve(编号) → 取注册记录
  └ acquire 设备锁（进程内 + 文件锁，超时 30s → busy）
      └ verify_identity：在线 / 名称一致 / host 一致
          └ pointer.ready 检查（home 之外的动作要求就绪）
              └ 调 iPhone-use（device=完整 id）→ 回显校验
events.jsonl 记录 action 或 error（含 latency_ms、status、params）
```
返回 `ActionResult{ok, device, action, latency_ms, status, error, payload}`；CLI 退出码 0 成功、2 失败、3 策略拒绝。

## 3. 一致性保证（目标 7）
- 请求与响应设备 ID 必须相等（`DeviceMismatch`）。
- 名称漂移、host 漂移直接拒绝并写 `error` 事件。
- 截图响应头 `X-Device` 同样校验，用于把画面与编号对上。
- 建议在首次注册与每级扩容后做一次“肉眼回归”：对每台 `ifarm run N tap --x 0.5 --y 0.5` 并观察只有第 N 台有反应。

## 4. 限制
- iPhone-use `/type` 只支持 ASCII；中文走输入法（`ctrl+space` 切换后输入拼音）或通用剪贴板 + `cmd+v`。
- 画面只有截图接口（JPEG/PNG，默认长边 1200）；实时画面看 iPhoneUse 原生窗口或 `/viewer`。
- 手机必须解锁亮屏；`home` 只能唤醒。
