# 01 软件安装步骤（第一阶段：3 台 iPhone）

目标：在 MacBook Pro M5 Pro 上安装 iPhone-use 与 `ifarm`，连接 3 台 iPhone，完成 USB 识别、蓝牙配对与独立控制验证。

## 1. Mac 准备
1. macOS 14 或更高（`sw_vers`）。
2. 安装 Homebrew（https://brew.sh）与 Xcode Command Line Tools（`xcode-select --install`）。
3. 群控期间禁止休眠：`sudo pmset -a sleep 0 disksleep 0`，并在终端保留 `caffeinate -dims &`。
4. 提高打开文件数：在 `~/.zshrc` 加 `ulimit -n 10240`。
5. 系统设置 → 隐私与安全性：稍后为 iPhoneUse.app 授予 **摄像头**、**蓝牙**；若使用 `scripts/preflight_mac.sh` 需终端“完全磁盘访问”非必需。

## 2. 安装
```bash
cd iphone-farm
./scripts/install_mac.sh            # 默认下载 Releases 的 iPhoneUse-v1.0.1-macOS-universal.zip 到 /Applications
# 或源码构建（便于后续打补丁）：
./scripts/install_mac.sh source     # git clone + swift build -c release → ~/iPhone-use/.build/release/iphone-use
```
脚本同时安装 `libimobiledevice`（`idevice_id`/`ideviceinfo`，用于 UDID 交叉核对）、`pymobiledevice3`（可选）与本项目虚拟环境 `.venv`（`ifarm` 命令）。

首次打开：`open -a iPhoneUse` → 若被拦截，到“系统设置 → 隐私与安全性”点“仍要打开”。如需无窗口后台常驻：
```bash
open -a iPhoneUse --args --resident-quiet     # 或 IPHONE_USE_RUN_MODE=residentQuiet
curl -s http://127.0.0.1:7390/status | head -c 400
```

## 3. 每台 iPhone 的准备（3 台先做，30 台同样）
1. **改名**：设置 → 通用 → 关于本机 → 名称 → `IF01`、`IF02`、`IF03`（注册编号依赖此名称）。
2. **不自动锁屏**：设置 → 显示与亮度 → 自动锁定 → 永不；亮度调低；关闭“抬起唤醒”。
3. **测试机建议去掉锁屏密码**（否则 Home 只能唤醒不能解锁，需要人工输入密码）。
4. **AssistiveTouch**：设置 → 辅助功能 → 触控 → AssistiveTouch → 开。
5. 语言建议英文（Spotlight 搜索 “Settings/Messages” 用 ASCII 更可靠）；中文系统也可，但 `open_app` 的 `query` 需能被 Spotlight 命中。
6. 插入 SIM，确认有信号（短信测试见 docs/08）。

## 4. 连接与配对（逐台）
1. 用 **数据线**（非纯充电线）接到 A-832 的某个口，A-832 上行接 Mac。iPhone 弹出“信任此电脑”→ 信任并输入密码。
2. Mac 上 iPhoneUse 会为该机打开一个窗口；`ifarm devices` 应看到 `id`、`name=IF01`。
3. 手机：设置 → 辅助功能 → 触控 → AssistiveTouch → 设备 → 蓝牙设备 → 选择 **“iPhone Use”**（或控制窗口显示的 Mac 名称）。
4. 等待 iPhone-use 自动探针匹配（指针会在屏幕上跳几下）；`curl -s localhost:7390/status` 中该设备 `bluetooth=true`、`pointer.ready=true`、`bluetoothHosts[].screen.id` 等于它的 id。
5. 若 `unmatchedHosts` 非空：`curl -X POST localhost:7390/match -d '{"force":true,"probe":true}'`；仍不行用 `/pair` 指定（docs/05）。
6. 指针落点不准：`curl -X POST localhost:7390/calibration/auto -d '{"device":"<完整id>"}'`，或按 user-guide 跑 `scripts/calibrate-pointer.py`。

## 5. 独立控制验证（3 台）
```bash
. .venv/bin/activate
./scripts/preflight_mac.sh          # USB 树应列出 3 台 iPhone，idevice_id -l 列出 3 个 UDID
ifarm check                          # iphone_use.reachable=true, devices=3, bluetoothHosts=3, unmatchedHosts=[]
ifarm register                       # 名称 IF01..03 → 编号 1..3，交叉核对 UDID，记录蓝牙 host
ifarm verify                         # mismatch=0
ifarm run 1 home && ifarm run 2 home && ifarm run 3 home
ifarm run 1 tap --x 0.5 --y 0.5      # 只有编号 1 的手机应有反应（肉眼确认）
ifarm run 2 swipe --params '{"points":[{"x":0.5,"y":0.8},{"x":0.5,"y":0.3}]}'
ifarm run 3 open_settings            # 只有编号 3 打开“设置”
ifarm screenshot 1 && ifarm screenshot 2 && ifarm screenshot 3   # reports_out/screens/IF0x_*.jpg 应与对应手机一致
```
验收标准：
- `system_profiler` 与 `idevice_id` 都识别到 3 台；
- 3 台 `pointer.ready=true`，且 `ifarm verify` 无名称/host 不一致；
- 对编号 N 的动作只在第 N 台发生（肉眼 + 截图回显 `X-Device` 一致）；
- 连续 10 分钟 `ifarm monitor --duration 600` 无 `ble_drops`。

## 6. 常见问题
| 现象 | 处理 |
|---|---|
| `/devices` 没有该机 | 换数据线/换口；手机解锁并重新“信任”；`system_profiler SPUSBDataType` 看是否枚举；iPhoneUse 摄像头权限 |
| 画面有、控制无 | AssistiveTouch 蓝牙设备里重新连接 “iPhone Use”；看 `/status` 的 `bluetoothHosts`/`unmatchedHosts`；`/match` |
| 配对日志 “Denying pairing request / 4815” | Mac 拒绝配对：重启 iPhoneUse，等到日志 “advertising as iPhone Use” 再从手机连接；不要随意删配对记录 |
| 点击位置偏 | `/calibration/auto`；保持竖屏、关闭缩放 |
| 中文输入 | `/type` 只支持 ASCII：`ctrl+space` 切拼音后输入拼音，或通用剪贴板 + `cmd+v` |
