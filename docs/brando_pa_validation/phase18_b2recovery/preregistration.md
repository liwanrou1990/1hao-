## 1. 原 B2 机制（审计事实，代码与 config 读取）
NORMAL → 回撤 10% → RISK_REDUCED（仓位上限 50%）；回撤 20% 或单日跌 15% → EMERGENCY_HALT（全部卖出）→ 次日 COOLDOWN，长度 = 30 天 × min(熔断计数, 3)（即 30 / 60 / 90 天，计数在 NORMAL 连续 180 天后清零）→ RECOVERY（上限 50%，60 天，期间相对恢复期高点回撤 10% 再次熔断）→ NORMAL。买入只在资产收盘 > SMA200 时发生。日线复现引擎中仓位上限提高（RECOVERY → NORMAL）本身不会补仓，只有持有集合变化时才再平衡（第十阶段既有行为，原样保留）。

## 2. 审计：7 次不必要的长期空仓（第十七阶段分类）
对每次记录：触发时的回撤 / 单日跌幅与熔断计数、冷静期长度、恢复期起止、价格回到卖出价与回到 SMA200 上方的天数、实际回补条件、错过的涨幅。

## 3. 变体（参数事先固定，均有先验理由，不针对任何年份调参）
| 编号 | 名称 | 规则 |
|---|---|---|
| V0 | 原 B2 | 不变（固定对照） |
| V1 | 固定 30 天冷静期 | 冷静期恒为 30 天（不随计数加长） |
| V2 | 固定 60 天冷静期 | 恒为 60 天 |
| V2b | 固定 90 天冷静期 | 恒为 90 天（用户描述的“原版”，实际原版是 30/60/90 递增，此项单列对照） |
| V3 | 趋势确认提前结束冷静期 | 冷静期内，熔断后至少 14 天，且任一资产连续 5 个日线收盘 > SMA200 → 提前进入 RECOVERY（上限 50%、60 天、10% 再熔断规则不变）；否则按原版冷静期到期 |
| V4 | 周线结构恢复 | 冷静期内，熔断后至少 14 天，任一资产在周线收盘时：周收盘 > 20 周 SMA，且最近完整一周的周最低价 > 熔断以来的最低周最低价（守住支撑、出现更高低点）→ 提前进入 RECOVERY；否则按原版到期 |
| V5 | 阶梯恢复（原冷静期） | 冷静期同原版；RECOVERY 上限改为分段：前 20 天 25%、20–40 天 50%、40–60 天 75%，60 天后 NORMAL 100%；上限提高时补足仓位 |
| V6 | 趋势确认 + 阶梯恢复 | V3 的提前结束条件 + V5 的阶梯上限 |
| C0 | 原版 + 上限提高时补仓（诊断对照） | 与 V0 相同，仅在仓位上限提高时补足仓位；用于把“阶梯”效果与“补仓”效果分开 |
SMA200、5 日、14 天、20 周、阶梯比例均为事先选定的常用值，**不做网格搜索、不择优**。

## 4. 数据与时间顺序（不宣称独立盲测）
- BTC：第十六阶段拼接日线；ETH：2016-05-18 → 2017-08-16 Coinbase ETH-USD（2 个缺失日前向填充并标注），此后第十阶段数据集。
- **早期检验段** 2017-01-01 → 2017-12-31：B2 在本项目中从未在此段运行过，但 2017 年价格走势众所周知，不是盲测。
- **开发段** 2018-01-01 → 2021-12-31：包含 2021 年的典型空仓案例，属于开发数据。
- **重复检验段** 2022-01-01 → 2026-11-07：已在第十至十七阶段被反复研究，属于重复检验数据，不是盲测。

- 成本：单边 15 bps（与 Mac 一致）与 25 bps；另报 0 / 50 bps 敏感性。每个窗口独立从 10,000 USDT 起算，指标预热使用此前历史。

## 5. 指标
最终 USDT 净资产与净利润（清仓口径）；最大回撤与最长回撤天数；牛市参与（上涨日对 50/50 的收益捕获率、牛市月份平均仓位）；熊市暴露（下跌日捕获率、熊市月份平均仓位；牛熊按第十阶段口径：BTC 90 日收益 ±20%）；不必要空仓天数（第十七阶段分类）；重新入场后亏损率（熔断后的首次买入，其后 60 天组合净值低于入场日的比例）与 90 天内再次熔断次数；手续费、滑点、成交次数；与原 B2、BTC SMA200、BTC 买入持有、50/50 买入持有的差距；逐年相对原 B2 的差额。

## 6. 判定（事先写明）
变体具有“增量优势”当且仅当：在早期检验段、开发段、重复检验段**三个窗口**，15 与 25 bps 下**全部**满足：
1. 清仓净收益 ≥ 原 B2；
2. 最大回撤 ≥ 原 B2 最大回撤 − 3 个百分点（不显著更差）；
3. 若该窗口熔断后重新入场 ≥ 3 次，重新入场亏损率不高于原 B2 + 20 个百分点。
另外，全样本净收益须高于原 B2，且逐年相对原 B2 为正的年份 ≥ 一半（防止单一年份驱动）。
- 满足 → 只建议进入**下一阶段独立影子观察**（新影子账户，原 B2 不变）。
- 不满足 → 维持原 B2 不变。C0 是诊断对照，不参与推荐。
