## 1. 冻结的观察基准（不再优化）

**FIX25_Y：25% BTC + 75% USDT，年度再平衡。** 与第二十阶段 `ALLOC_25_Y` 完全相同的代码与参数：
- 目标权重 BTC 25%、USDT 75%；USDT 不计利息。
- 建仓：观察起点当日收盘决策，次日开盘成交。
- 再平衡：每年 1 月第一个交易日开盘，调回 25%；其余时间不交易；差额 < 5 USDT 不交易。
- 不止损、不择时、不因回撤预警交易。
- 成本：单边手续费 10 bps + 基础滑点 5 bps + 平方根流动性冲击（σ 前 20 日 × √(订单 ÷ 当日成交额)，上限 100 bps）；BTC 数量精度 0.00001。
- 冻结方式：规则文本、参数与相关源文件的 SHA-256 写入冻结清单；每次运行前校验，不一致则拒绝运行并记录 `frozen_rule_violation`。

## 5. 50% 回撤预算监测

- 回撤 = 清仓净值相对观察以来最高清仓净值的跌幅。
- 研究性风险警报：回撤首次跌破 35% / 40% / 45% / 50% 时各产生一条警报（回到高水位后重新计数）。
- 警报只记录与显示，**不触发任何交易**；50% 是研究预算，不是止损。

## 6. 压力测试（情景，不是预测）

对 FIX25_Y（并列对照）：
1. 即时冲击：BTC −30 / −50 / −70 / −80 / −90%；USDT 对美元脱锚 −5 / −10 / −30 / −50 / −100%；两者组合。以美元计价（USDT 脱锚时以 USDT 计价没有意义）。B2 / SMA200 分“持仓中 / 空仓中”两种状态。
2. 路径：年内暴涨 k 倍后暴跌（再平衡前）；连续 n 年下跌（每年初再平衡加仓）；历史最坏区间路径放大。用配置引擎在合成行情上运行。
3. 执行：单边成本 15 → 50 / 100 / 200 bps；冲击系数 ×3 / ×10；成交量降为 1/10、1/100（流动性不足）；再平衡延迟 1 / 3 / 7 / 14 天（行情延迟）。在 2014–2026 全样本上重算。
4. 组合：最坏历史区间 + 成本 200 bps + 区间低点 USDT 脱锚 20%。
报告所有可能超过 50% 预算的情景及其触发条件。

## 7. 前瞻评估标准（事先规定）

只评已到期窗口（30 / 90 / 180 / 365 天，之后每年）；任何窗口都不足以证明“优于买入持有”。
- **风险控制（FIX25_Y 的主要假设）**：(a) 最大回撤 ≤ 50%；(b) BTC 自高点回撤 ≥ 30% 的任何区间，FIX25_Y 回撤 ≤ BTC 回撤 × 0.5；(c) 每年交易成本 ≤ 期初净值 0.2%。
- **收益参与**：BTC 上涨区间，FIX25_Y 收益 ≥ BTC 收益 × 0.15（理论约 0.25，扣除再平衡与成本）。
- **与原 B2、BH 比较**：报告清仓净值、收益差、最大回撤、收益回撤比、上涨参与、时间在市；至少一个完整牛熊周期（约 4 年）之前不下“更好 / 更差”的结论。
- **完整性**：哈希链 100% 可验证；无 `frozen_rule_violation`；数据缺口与来源切换全部有记录。
- 任一风险条件失败 → 报告失败与原因，不修改规则；是否停止观察由你决定。
