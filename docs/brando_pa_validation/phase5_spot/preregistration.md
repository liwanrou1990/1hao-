## 2. 固定规则与参数（零自由度）

- 趋势状态（日线）：SMA50/SMA200、SMA50 20 日斜率、|SMA50−SMA200| ≤ 0.5 ATR(1d) 为 RANGE、60 日收盘新高/新低做结构修正、状态切换确认 1 个日线收盘。4h 结构沿用 HH/HL/LH/LL；1h 用于交易机会。
- 模型 A 趋势持仓：日线 BULL → 买入 100%（双资产 50%）并持有；只按退出模式退出；允许再入场。
- 模型 B 核心+战术：核心 50%（趋势管理）+ 战术 50%（Brando A/B 买点，单笔风险 = 战术资金 × 1%，策略 C 只卖战术袖子 50%）；核心不受战术信号影响；总敞口 ≤ 100%。
- 模型 C 趋势过滤 Brando：日线 BULL 且 4h 非 down 时才用 Brando A/B 买入（单笔风险 1%，上限 100%）；策略 C 只减仓 25%。
- 原 Brando 现货（第四阶段规则，不含 1R 保本/摆动低跟踪，改用本阶段三种退出之一，以便同口径比较；第四阶段原始结果另见 docs/23）。
- 退出模式（独立运行，不事后挑选）：A 结构止损（战术 = Brando 结构止损；趋势入场 = min(最近已确认 1h 摆动低, SMA50 − 1 ATR(1d)) − 0.2 ATR(1h)）；B 日线趋势失效（离开 BULL 持续 2 个日线收盘）；C ATR 跟踪（最高收盘 − 3×ATR(1d)，只上移）。退出模式作用于核心/趋势仓位与模型 C、原 Brando 的持仓；模型 B 的战术袖子按规格“由 Brando 价格行为管理”，始终用 Brando 结构止损 + 策略 C 卖出，不随退出模式变化（这一点在验证窗冒烟运行后、保留集运行前明确）。取消 1R 保本默认规则。
- 硬性限制（全部模式）：账户回撤 ≥ 20% 暂停新买入（收窄到 10% 恢复）、单资产持仓 ≤ 100%（双资产 50%）、单日线跌幅 ≥ 15% 全部退出、现金/持仓不为负、无杠杆、无做空。

## 4. 判据（不调整）

“改善”须同时满足：相对原 Brando 现货，全周期（full_1h 2022-04→2026-11）与保留集两个窗口总收益更高且最大回撤不更差；相对合理基准（同标的买入持有与 SMA200 基准），风险调整收益（Calmar 或 Sharpe）不低于基准中较好者，且不是靠长期空仓（上涨月份捕获率 < 50% 的组合不得称为“趋势参与改善”）。任一不满足 → 报告为未达到。
