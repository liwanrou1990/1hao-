- **前瞻检验**：自本阶段起，模拟盘（延迟数据模式）逐根记录的信号与 CoinGecko 永续快照单独保存，不与历史回测混合。

## 2. 预先登记的假设（只此三条，不新增）

H1（模式 B：突破后的二次确认）：在 4h 有效突破 1W/1D 区域之后，等待首次回踩进入区域并由执行周期**已确认微结构**（摆动低点 + 收盘突破其后的反弹高点）确认入场，并以微结构低点作止损，其扣费后期望 R 将高于原策略 A（止损挂在区域另一侧）。预期机制：止损距离从 3–4 ATR 降到 1–2 ATR，净盈亏比提高；代价是部分突破无回踩而错过。

H2（模式 A：结构位附近确认入场）：不要求事先突破，价格到达 1W/1D 支撑/阻力后由同样的微结构确认入场（4h 逆势不做）。预期：交易数多于 H1，期望 R 低于 H1（无突破前提的区域反应质量更低）。

H3（止损结构）：对同一组入场信号，“微结构止损”相对“区域另一侧 + ATR 缓冲”会提高被噪声扫损的频率（MAE 在 0.5–1R 之间的亏损占比上升），但净期望仍更高；“区域另一侧无缓冲（fixed_structure）”最差。

## 4. 成功 / 失败判据（与第二阶段 Strategy Evaluator 完全相同，不调整）

样本外（L2 保留集 + L1 锁定集分别报告）：交易数 ≥ 30、ExpR > 0、PF ≥ 1.1、最大回撤 ≤ 20%、均值 R 95% 置信下限 ≥ −0.05 → “仅研究”；置信下限 > 0 且 ≥ 50 笔 → “模拟盘候选”。任一不满足 → **失败**，报告中明确标记，不包装。

## 5. 禁止事项

不删除亏损交易；不降低成本假设（基线 6/5/10 bps + 资金费 0.0001/8h）；不放宽止损距离上限、总风险、单日亏损限制；不用事后行情决定限价改市价；不使用未来数据；锁定集只运行一次，结果无论如何都写入报告。
