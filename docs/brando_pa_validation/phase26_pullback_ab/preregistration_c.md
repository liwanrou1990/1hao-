## 1. 两个版本

**A = 现行规则：** 第十一阶段 V4 主配置，代码不改。

**C = 只改一处第一目标规则：**
- 入场评估时，如果拟入场价上方**没有任何**已确认阻力区（当时可见的 `resistances_above(zones, entry_ref)` 为空），第一目标 T1 = 拟入场价 + **3 × ATR14**（ATR 取信号日的值）。
- 上方**已有**已确认阻力区时，规则和 A 完全一样：从这些阻力里找第一个距离 ≥ 1.5 倍风险的作为 T1，找不到就拒绝。
- T2 的规则不变：T1 上方有下一个已确认阻力就用它，否则用测量幅度，再没有就不设。
- 净盈亏比 ≥ 1.5 的检查、信号检测（回调 + 突破回踩）、失效价、仓位、退出、成本（单边 25 bps）、次日开盘成交，全部不变。
- C 对两类信号都适用，因为它们共用同一个入场评估。

**倍数为什么是 3：** 直接沿用项目里已有的常数，即第十一阶段退出 C 的跟踪止盈“最高收盘 − 3 ATR”。这个倍数不是从 1.5R 倒推出来的，也没有根据任何回测结果挑选，只测这一个，不做敏感性挑选。

**照实说明：** 上一轮审计看过 4 条的风险大小（1.7–4.8 ATR）。按 3 ATR 目标，多数信号的 R 会低于 1.5，仍会被拒。这个倍数是在知道这一点的情况下事先固定的。
