## 2. 固定规则（零自由度）

### 2.1 策略 A（对照组，不改动）
第五阶段 `sma200_benchmark` 的规则原样：只用**已收盘**日线，日线收盘 > SMA200（200 个日线收盘的简单均值；不足 200 根时无信号 = 空仓）→ 目标仓位 100%（等权双资产时每资产 50%），否则 0%；信号在日线收盘所在的执行 K 线收盘确认，在**下一根执行 K 线开盘**成交；买入用可用现金 × 99.9%（保留 0.1% 现金缓冲，与第五阶段一致）；最小订单 10 USDT。

### 2.2 策略 B（唯一一种收盘确认方案）
与 A 完全相同，只多一条：**状态切换需要连续 3 个已收盘日线在 SMA200 的另一侧**（上穿与下穿对称）。3 日是预先选定的惯例值，不做 2/4/5 等搜索；事后只做 ±1 日敏感性**报告**，不用于选择。若 B 没有按 §4 判据改善，不采用 B，明确保留 A。

### 2.3 仓位管理层
目标仓位 = 趋势层目标 × 风险层上限。动作只有 BUY（补到目标）、HOLD、REDUCE（降到上限）、EXIT（清零）。双资产等权：每资产目标价值 = 50% × 当前权益，只在信号或风险状态变化时调整，不做定期再平衡。现金与持仓不得为负；无杠杆、无做空、无借币、无合约。

### 2.4 风险层：回撤熔断状态机（预登记参数）
每个日线收盘评估一次（与趋势层同一决策时刻），动作在下一根执行 K 线开盘执行。回撤 DD = 权益 / 风险参考高水位 − 1；风险参考高水位 = 自窗口起（或自最近一次进入 RECOVERY 起，见下）日线收盘权益的最大值；账户的全程高水位另行记录用于报告。

| 状态 | 允许的最大仓位 | 进入条件 | 离开条件 |
|---|---|---|---|
| NORMAL | 100% | 初始；RISK_REDUCED 且 DD > −5%；RECOVERY 满 60 个日历日且期间未再触发 | DD ≤ −10% → RISK_REDUCED；DD ≤ −20% → EMERGENCY_HALT |
| RISK_REDUCED | 50%（超出部分下一开盘减仓） | NORMAL 且 DD ≤ −10% | DD > −5% → NORMAL；DD ≤ −20% → EMERGENCY_HALT |
| EMERGENCY_HALT | 0%（下一开盘全部卖出） | 任一状态 DD ≤ −20%；RECOVERY 中相对恢复期高点回撤 ≤ −10% | 下一个日线收盘 → COOLDOWN；熔断计数 +1 |
| COOLDOWN | 0%（禁止买入） | 来自 EMERGENCY_HALT | 持续 30 × min(熔断计数, 3) 个日历日（30/60/90）后 → RECOVERY |
| RECOVERY | 50% | 冷静期结束 | 满 60 个日历日且未再触发 → NORMAL；相对恢复期高点回撤 ≤ −10% → EMERGENCY_HALT |

补充规则：进入 RECOVERY 时风险参考高水位重置为当时权益（否则全程高水位会使熔断成为永久停机）；进入 NORMAL 后连续 180 个日历日未进入 EMERGENCY_HALT 则熔断计数清零；单日线跌幅 ≥ 15% 作为异常风险事件直接进入 EMERGENCY_HALT（沿用第五阶段硬限制）。数据失败安全态：最新 K 线过期（> 3 个周期）或出现缺口时，禁止新买入、不强制卖出、只记录；数据恢复后按正常规则继续。状态机是有限的：任何一次熔断之后最多 90 日冷静 + 60 日恢复即可回到 NORMAL，不存在永久禁买。

三种对照模式（全部运行、全部报告）：(i) 第五阶段原规则（DD ≤ 20% 暂停买入、收窄到 10% 恢复，全程高水位，不强制卖出）；(ii) 上述状态机；(iii) 无熔断（诊断用，不作为可采用方案）。

## 4. 验收判据（独立、不调整）
以 full_1h 零成本为主判据，其余窗口与含成本为稳定性检查；全部数字照报，不删除、不挑选。
1. 策略 B 改善：BTC 与 ETH 两个单标的在 full_1h 上**同时**满足总收益 ≥ A 且最大回撤优于 A（更小）；否则保留 A。
2. 熔断 (ii) 可接受：(a) 每次熔断后在冷静期 + 恢复期内恢复买入资格（无永久停机，状态日志可验证）；(b) 最大回撤 ≤ 无熔断 (iii)；(c) full_1h 总收益 ≥ 原规则 (i)（BTC 与 ETH）。任一不满足 → 报告为未达到，保留“无状态机 + 趋势层自身退出”作为默认并说明。
3. 上涨参与：最终方案的上涨月捕获率不低于 A 的 90%。
4. 交易次数：不超过 A 的 2 倍。
5. 成本后：含成本仍优于 100% USDT，且相对 A 的排序不变。
6. 稳定性：B − A 的总收益差与回撤差在 train / valid / 已观察测试窗 / full_4h 上符号一致才可称为“稳定”；±1 日敏感性只报告。
7. 无未来数据：截断一致性测试（截去末尾历史不改变此前任何一天的信号与状态）；无杠杆、无负现金、无负持仓的逐根断言。
若 A（原始 SMA200）在判据下仍是最佳，明确保留 A，不交付更复杂方案。
