**总判定（按预先登记判据，未调整）**：

1. **SMA200 基准审计通过，第五阶段数字被完整复现。** 在第五阶段数据截止（2026-11-06 09:00 UTC）下，三套相互独立的实现（第五阶段 `sma200_benchmark`、本阶段纯 numpy 日线级复算、本阶段三层引擎）逐根权益最大相对差 4×10⁻¹⁶：BTC +231.9%（最大回撤 −33.4%，17 次买入）、ETH +113.9%（−40.6%，14 次买入）；含成本 10 bps + 5 bps 时三套同为 +215.9% / +105.4%，手续费核对一致（844 / 472 USDT）。逐项核对：SMA200 在 2018-03-04 才形成，之前无信号；每一笔成交都在日线收盘后的第一根 1h K 线（UTC 00:00）开盘、成交价等于该根开盘价；现金最低 9.7 USDT、持仓从不为负、敞口 ≤ 99.96%（0.1% 现金缓冲），权益恒等式误差 0；截断末尾 120 根日线不改变此前任何信号；若错误地使用当日尚未收盘的日线，BTC 会变成 +928%、ETH +571%——报告的数字没有这种未来数据。持仓段内回撤：BTC 17 段平均 55 天，段内最大回撤最差 −27%、中位 −5%，65% 的持仓段以亏损结束；ETH 最差 −35%、71% 亏损段。**这是正常的趋势跟随分布：多数小亏、少数大赚，收益来自 2023 与 2024–2025 的几段长持仓。**
2. **策略 B（连续 3 个日线收盘确认）没有改善，明确不采用。** full_1h 零成本：BTC +125.3%（回撤 −45.6%）对 A +231.3%（−33.4%）；ETH +45.7%（−48.3%）对 +114.6%（−40.6%）。确认把卖出从 16 / 13 次减到 8 / 6 次，但代价是在每一次快速下跌里多持有 3 天，回撤更深、再入场更晚（卖后再买的中位间隔从 6–8 天拉长到 22–84 天，错过的行情更多）。B − A 的收益差在 train / valid / 已观察测试窗 / 4h 长历史上全部为负（判据 6 的收益符号一致，但回撤符号不一致，故“稳定性”判据也未通过）。事后 ±1 日敏感性同样全部劣于 A（2 日：BTC +145% / ETH +70%；4 日：+148% / +21%），说明这不是确认天数没调好，而是**对 SMA200 这种慢信号再加延迟只会损失趋势末端的保护**。
3. **原规则“回撤 20% 暂停买入”被逐根证实为永久停机。** full_1h 上 BTC 最长禁买 855 天、ETH 1,177 天、4h 长历史 2,640 / 2,674 天，且期末仍在禁买；ETH full_1h 因此只剩 +14.9%（A 无熔断 +114.6%）。**新的有限状态机消除了这个问题**：每次熔断后最多 90 日冷静 + 60 日恢复即回到 NORMAL，BTC 最长禁买 31 天、ETH 91 天，状态日志可逐条核对（BTC 1 次熔断：2025-03-20 → 04-20 冷静结束 → 06-19 恢复完成；ETH 4 次，含一次恢复期再触发）。它把 full_1h 最大回撤从 −33.4% / −40.6% 压到 −22.5% / −28.1%，等权从 −31.0% 到 −21.8%；在已观察的测试窗（2025-07 →）ETH +38.0%（无熔断 +16.1%）、等权 +28.6%（+10.8%）；在 4h 长历史上 BTC +977%（回撤 −44%）对无熔断 +1,053%（−64%），ETH +612%（−30%）对 +1,620%（−75%）。
4. **但状态机没有通过预登记判据，不得宣称改善。** 判据 2(c) 要求 full_1h 总收益不低于原规则：BTC +161.3% 对原规则 +163.2%，差 1.9 个百分点，未通过（ETH +97.5% 对 +14.9%，通过）。判据 3 要求上涨月捕获率 ≥ A 的 90%：BTC 46% 对 68%、ETH 33% 对 51%，未通过。判据 5 含成本排序：ETH 含成本时状态机（+110.9%）反超 A（+106.1%），与零成本排序不一致，未通过。原因很明确：状态机 56%（BTC）/ 29%（ETH）的时间处在 RISK_REDUCED（回撤 ≥ 10% → 上限 50%）——SMA200 策略的权益曲线在大部分时间里本来就离高水位超过 10%，10% 这个减仓阈值低于这条策略的正常回撤幅度，于是“减半仓”成了常态而不是异常保护，换来的是回撤从 −33% 降到 −22%、收益从 +231% 降到 +161%。**这是回撤与参与度的直接交换，不是免费午餐。**
5. **最终选择**：趋势层 = 原始 SMA200（策略 A），不交付更复杂方案。风险层：按任务硬约束（不得仅因无熔断收益更高而取消保护、不得无条件自动恢复满仓），受保护的默认仍是“策略 A + 有限状态机”，但它带着“未通过判据 2(c)/3/5”的标注；“策略 A + 仅趋势退出 + 现货硬约束”是所有被测组合中收益最高的（full_1h BTC +231% / ETH +115% / 等权 +171%），其代价是 −33% / −41% / −31% 的回撤且没有趋势退出以外的保护。两者全部报告，由使用者按可承受回撤选择；本阶段不替使用者做这个选择。
6. **交易频率：第五阶段模型 B 的上千笔战术交易是来回磨损，不是保护。** BTC 战术袖子 1,033 笔（每年 285 笔），持仓中位 0.9 天、53% 不到 1 天、93% 不到 7 天，胜率 35%；914 次卖出里 99.8% 随后再买、中位间隔 13 小时、57% 以更高价再买；按卖后标的走势分类：**来回磨损 511 次、中性 383 次、保护性（卖后标的再跌 ≥ 10%）只有 20 次**。零成本净 +2,210 USDT，含成本变成 −1,621 USDT（ETH：803 笔，−868 → −1,782）。原 Brando 现货同样：59 笔、持仓中位 0.5 天、胜率 24–29%、零成本已亏损。结论维持：**战术信号停止优化，Brando 价格行为模块默认关闭**（`trendsys.brando_signals.enabled: false`），研究与可视化保留。对比之下，策略 A 每年只卖 3.5 次，卖出里 62% 是持仓不到 7 天的短暂跌破（BTC 16 次中 11 次是来回磨损、4 次是保护性），但 4 次保护性退出避开的是 −20% 以上的下跌，这正是 SMA200 回撤只有买入持有一半的来源。
7. **BTC / ETH / 等权**：等权在全部窗口的回撤低于单独 ETH、收益介于两者之间（full_1h +171%、回撤 −31%；已观察测试窗 +10.8%，状态机下 +28.6%）；没有依据选单一标的——与第四、五阶段一致，单标的结果随窗口翻转（已观察测试窗 BTC +3%、ETH +16%；全周期相反）。
8. **成本**：10 bps + 5 bps 对低频的 SMA200 影响有限（BTC +231% → +215%，ETH +115% → +106%），对战术交易是致命的（见第 6 条）。
9. **数据与可信度**：没有新历史数据。全部窗口在前五阶段已被观察，holdout 明确标注为“已被观察的测试窗”；真正未使用的 2022-01→03 仅 3 个月且全程在 SMA200 下方（所有策略空仓或一次小亏），没有统计力。本阶段的可信结论只有三条：基准复现无误、原规则是永久停机、状态机以参与度换回撤；任何正收益都不是样本外证据。
