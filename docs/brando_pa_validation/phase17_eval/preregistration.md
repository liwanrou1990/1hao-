## 1. 矿工成本可信度审计
没有真实成本数据（矿企披露与剑桥 CBECI 均不可得），因此用三种不依赖真实成本的方法估计误差：
1. **假设敏感性网格**（模型本身的不确定性）：机队规则 {新增 = 最新机型，新增 = 最新与上一代的几何平均} × 交付滞后 {60, 90, 180 天} × 最长服役 {4, 5, 6 年} × 淘汰倍数 {5, 10, 20} × PUE {1.05, 1.10, 1.20} × 电价 {0.04, 0.05, 0.06, 0.07, 0.08 美元每度} × 矿机规格误差 {−15%, 0, +15%}。全部为“同样合理”的取值，不择优。
2. **跨模型分歧**：第十六阶段代际模型（中值）与第十五阶段锚点模型（中值）在 2018 → 的比值分布。
3. **可观测一致性**（价格只用于检验，不进入成本）：若模型成本准确，模型说“平均矿机亏损”（价格 / 成本中值 ≤ 1）时，此后 60 天算力增长应明显低于“盈利充足”（价格 / 成本中值 ≥ 1.5）时。

关键日期：2015-01-14、2018-12-15、2020-03-12、2022-11-21、最新已收盘日。

**“严重误差，不可作为阈值型策略基础”的判定（满足任一条）：**
- (a) 至少 2 个关键日期的网格成本最大 / 最小 ≥ 2.0；
- (b) 至少 2 个关键日期上，判断“价格 ≤ 成本”的网格组合比例在 20%–80% 之间（即结论随合理假设翻转）；
- (c) 跨模型比值的 5%–95% 区间超出 [0.67, 1.5]；
- (d) 可观测一致性不成立：价格 / 成本 ≤ 1 时的 60 天算力增长中位数不低于价格 / 成本 ≥ 1.5 时。
判定为严重误差 → 第十六阶段的成本类研究冻结，不再以其为基础优化任何策略；成本区间只能作为带不确定性说明的背景展示。

## 2. B1（BTC SMA200）与 B2 错过的盈利机会（日线复现，与 Mac 账户 A / B 同规则；单边 15 bps）
窗口：B1 2014-01-01 → 最新（第十六阶段拼接日线）与 2018-01-01 → 最新；B2 与 B3（ETH SMA200）2018-01-01 → 最新。
对每个资产的每段“空仓期”（卖出成交 → 下一次买入成交）记录：卖出价、回补价、天数、空仓期内该资产最大跌幅与最大涨幅、按卖出时持仓价值计的节省 / 错失金额（= 卖出时持仓价值 × (回补价 / 卖出价 − 1)，正数 = 错失）。
分类（事先固定）：
1. **合理避险**：回补价 ≤ 卖出价。
2. **保护有效但回补更贵**：回补价 > 卖出价，且空仓期内最大跌幅 ≥ 20%。
3. **短期来回**：回补价 > 卖出价，最大跌幅 < 20%，空仓 ≤ 30 天。
4. **不必要的长期空仓**：回补价 > 卖出价，最大跌幅 < 20%，空仓 > 30 天。
期末仍空仓的一段单列为“进行中”，按最新价估算，不归类。另报告：上涨参与度（BTC 上涨日的收益捕获率）、下跌参与度、各年度与 BTC 买入持有的差距。
**不得**据此修改 B2 / SMA200 参数或规则。

## 3. 长期前瞻评估标准（适用于 Mac 三账户、第十三阶段影子账户与今后任何前瞻账户）
指标（全部扣除已发生的手续费与滑点，并按假设清仓口径再扣一次卖出成本）：
- 净资产：清仓口径 USDT 净值与净收益；
- 最大回撤：按清仓口径净值；
- 上涨参与度：在 BTC 上涨的日子里，账户收益合计 / BTC 收益合计；下跌参与度同理；
- 持仓周期：在市时间比例、闭合交易的平均 / 中位持仓天数、最长空仓天数；
- 与 BTC 买入持有的差距：同一前瞻起点、同样成本、一次买入的 BTC 账户的清仓净收益之差（B / REF 另报与 50/50、ETH 买入持有的差距）。
评估时点：30 / 90 / 180 / 365 天，之后每 365 天，以及每个完整牛熊转换（BTC 从 200 日均线上方转到下方再回到上方）。
**证据门槛**：365 天之前不得宣称“跑赢 / 跑输”，只能描述；至少经历一次 BTC 回撤 ≥ 20% 且一次上涨 ≥ 30% 之后，才允许对“避险价值 / 参与度”下结论。
**评分卡（365 天起每年评一次，阈值事先固定）**：
- 资本保护：清仓口径最大回撤 ≤ 同期 BTC 买入持有最大回撤 × 0.6；
- 上涨参与：BTC 同期涨幅 ≥ 20% 时，上涨参与度 ≥ 0.5；
- 净值：清仓净收益 ≥ 同期 BTC 买入持有清仓净收益 − 同期 BTC 买入持有最大回撤金额 × 0.5（允许为避险付出有限代价）；
- 警报：空仓 > 180 天且期间 BTC 上涨 > 30% → “长期踏空警报”；90 天内 ≥ 4 次往返且费用 + 滑点 > 净值 1% → “来回打脸警报”。
**结论规则**：三项全部达标 → 继续；一至两项不达标 → 继续观察并在报告中说明原因；三项全部不达标且持续两个评估年 → 停止评审。**任何结论都不自动修改策略**；如需改动，必须新预登记并新开前瞻账户，原账户继续运行作对照。
