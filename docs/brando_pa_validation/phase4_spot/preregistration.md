# 第四阶段（纯现货）预先登记

登记时间：2026-11-07，在任何保留集/锁定集运行之前提交。之后不修改；方向变化另起新登记。

## 1. 系统边界

- 只研究 BTC/USDT、ETH/USDT 现货；只做多；禁止杠杆、合约、借币、做空、负持仓。决策只有 BUY / HOLD / SELL；SELL 不得超过持仓。
- 默认理想研究模式：手续费 0、滑点 0；另以 10 bps 手续费 + 5 bps 滑点单独输出成本敏感性。
- 风险限制在理想模式下同样生效：单笔风险 1% 净值、单资产持仓上限 100%（双资产各 50%）、账户回撤 ≥ 20% 暂停新买入。

## 2. 两层关键位（固定规则，不为交易次数调整）

- 高周期（1w/1d/4h）区域只做背景：日线环境四分类、4h 结构、是否靠近高周期支撑、高周期阻力区（供策略 C 识别“关键阻力”）。**不**作为 1h 止损距离。
- 低周期执行区域：1h 已确认摆动高/低（分形 k=3，confirmed_idx = idx+3，确认后再过 3 根才有效），最近 120 根，容差 0.15 ATR(1h)，每侧最多 4 个；标记是否已被收盘越过（不含当前根）。止损全部挂在 1h 本地结构（回踩低点 / 跌破极值 − 0.2 ATR）。

## 3. 三个策略与退出（参数固定，见 config.spot，共 18 个数值，无网格）

A 突破回踩买入、B 跌破重新收复买入、C 阻力拒绝卖出（卖出 50%）；退出：结构失效硬止损（只上移）、浮盈 1R 保本、浮盈 1.5R 后跟随最近已确认 1h 摆动低点。无时间退出。

## 4. 数据使用史与窗口

与第三阶段相同：1h 2022-04→2026-11 已在前三阶段被反复观察；真正未使用的只有 1h 2022-01→03。本阶段规则是新的（本地结构 + 现货账本），但分析者先验受前期影响。窗口：训练 2022-04→2024-06（描述）、验证 2024-07→2025-06（描述）、**保留 2025-07→2026-11（半锁定，只运行一次）**、锁定 2022-01→03（真正未使用，极短）、4h 长历史 2018-01→2026-11（跨牛熊的描述性对照，不作判定）。

**本阶段不做任何参数选择**（零自由度）：训练/验证窗只用于描述，不据此修改规则；保留集结果无论正负都写入报告。
