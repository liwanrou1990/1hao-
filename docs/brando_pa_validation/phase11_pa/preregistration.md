## 2. 结构与区域（全部“当时已确认”）
- 摆动点：分形确认，日线左右各 k=3 根，周线 k=2；第 i 根的摆动点只在第 i+k 根收盘后可用（与现有 `swing_k` 口径一致）。
- 周线趋势 `WeeklyTrendDetector`：UP = 最近两个已确认周线摆动低点递增且最近已确认摆动高点递增，并且周收盘 > 周线 SMA30；DOWN 对称；否则 RANGE。
- 日线结构 `DailyStructureDetector`：HH/HL 序列（已确认摆动点）；SMA200 方向过滤：收盘 > SMA200 且 SMA200(t) > SMA200(t−20)。
- 支撑阻力区 `SupportResistanceZones`：用 ≤ t 的已确认日线 + 周线摆动点聚类（同一簇内价格相差 ≤ 0.5 × ATR14(日)）；区域 = [簇最低, 簇最高] 再向外扩 0.25 ATR；强度 = 触碰次数（周线摆动点计 2）；最近 400 日内的区域有效；阻力被日收盘有效突破后转为支撑（flip）。
- ATR：Wilder 14 日。

## 3. 入场策略（各自独立测试，不混合）
共同前置：周线趋势 UP 且日线 SMA200 过滤通过（策略 C 允许周线 RANGE）；入场前必须算出 entry_zone / invalidation / T1 / T2 / 预期净收益 / 净盈亏比 / 仓位 / 预估成本 / 理由；净盈亏比（扣双边成本后） < 1.5 → WAIT。
- **A 趋势回调买入**：价格回调到一个支撑区（或 flip 区）：某日最低价进入区域；回调期间至少出现 1 个“卖压减弱日”（下跌日成交量 < 20 日均量）；确认日：收盘 > 区域上沿、收盘 > 前一日最高、收盘位于当日振幅上 40%、成交量 ≥ 20 日均量 × 0.8。回调深度 ≤ 从最近已确认摆动低点到高点的 61.8%，否则不算回调（视为结构破坏）。确认日收盘决策，次日开盘买入。
- **B 突破回踩买入**：某日收盘 > 阻力区上沿 × (1 + 0.1 ATR/价) 视为突破（收盘确认）；此后 3–25 日内出现回踩：最低价进入 [区域上沿 − 0.5 ATR, 区域上沿 + 0.5 ATR] 且收盘不低于区域下沿；再企稳：回踩后收盘 > 回踩日最高 且成交量 ≥ 20 日均量 × 0.8。不在突破当日入场。
- **C 假跌破收复**（实验组，不进入最终推荐）：某日收盘 < 支撑区下沿（跌破）；5 日内出现收盘 > 区域上沿 且该日成交量 ≥ 20 日均量 × 1.2 且收盘位于振幅上 30%；失效价 = 跌破期间最低价 − 0.5 ATR；净盈亏比门槛 2.0。
- 卖出区：T1 = 入场价上方最近的已确认阻力区下沿（距离 ≥ 1.5 × 初始风险，否则取下一个）；T2 = T1 上方下一个已确认阻力区下沿，若无则 = 入场价 + 最近一段已确认摆动（低→高）的幅度（测量目标）。失效价 = 入场区域下沿 − 0.5 ATR 与最近已确认摆动低点 − 0.25 ATR 中的较高者（A/B）。
- 决策输出：BUY / WAIT / HOLD / REDUCE / EXIT，每条附理由字符串。

## 4. 退出方式（分别测试）
- **退出 A**：T1 全部卖出；失效价 / 结构失效（收盘 < 失效价）先到则止损。
- **退出 B**：T1 卖出 50%，剩余仓位止损上移至入场价；之后以“收盘 < 最近已确认更高低点（HL）”或 T2 退出。
- **退出 C**：不设固定目标；结构失效（收盘 < 最近已确认 HL）或 Chandelier 跟踪止盈（最高收盘 − 3 × ATR14）退出，允许持有 180 日以上。
- 所有退出均在触发日收盘决策、次日开盘成交；不设 30/60/90 日机械清仓。

## 5. 资金与风险
- 单笔计划风险 0.5% / 1.0% 权益：仓位 = 风险额 ÷ (入场参考价 − 失效价)，上限为单资产可配置额度。
- 组合最大配置 50% / 70% / 100%；BTC、ETH 同时持有时合计计划风险 ≤ 1.5 × 单笔风险（相关性约束；二者 2018–2026 日收益相关系数在报告中给出）。
- 回撤约束变体 20% / 30% / 40%：权益回撤 > 阈值 ÷ 2 → 新仓位减半；> 阈值 → 不新开仓，直至回撤收窄到阈值 ÷ 2 以内（现金保护与再入场规则）；这是约束变体，不是保证。
- 波动调整：ATR14 / 价格 > 过去 1 年 80 分位 → 仓位 × 0.5。
- 禁止杠杆 / 做空 / 负现金；最小下单 10 USDT；现金缓冲 0.1%。

## 10. 判定（事先写明）
- “优于原 Brando 模型”：同窗口同成本下假设清仓净资产更高**且**最大回撤更低，训练 / 验证 / 测试三段至少两段成立。

- “进入 90 天前瞻”：仅当上述两条对同一配置同时成立、且结果不依赖最大 5 笔交易（去掉后仍为正）、三种成本一致时建议；否则明确“证据不足”。
