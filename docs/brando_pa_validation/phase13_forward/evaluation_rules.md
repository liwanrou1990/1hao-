# 第十三阶段：前瞻验证客观评价规则（冻结于 2026-11-09，任何前瞻数据产生之前）

适用对象：影子账户 A（原 B2 状态机）、B（BTC SMA200）、C（BTC 持有）、D（ETH 持有）、E（BTC/ETH 50:50）、F（Phase 12 实验对照：B2 + 3 ATR 波动跟踪减仓）。起点 = 影子服务首次成功运行的 UTC 时刻（记录在各账户 `forward_start_utc`）；所有窗口按真实日历天计算，**未到期的窗口不评价、不填数**。

## 0. 总原则
- 只用前瞻期内按当时已确认信号产生的记录（`mode=forward`）；历史回测 / 回放数据不得与前瞻数据合并计算任何指标。
- 任何结论都先报告交易次数 n；n < 10 笔闭合交易时，收益类指标只能描述，不能宣称统计显著。
- 不以“BTC 枚数增加”“胜率”或“月收益”作为成功标准；主指标 = 扣费后假设清仓 USDT 净值及其相对 BTC 持有的差额。
- 不得因为前瞻结果不理想而修改策略参数后继续用同一前瞻期评价；修改即重新起算。

## 1. 30 天：数据、执行与审计质量（通过 / 不通过）
| 项 | 通过标准 |
|---|---|
| 服务连续性 | 轮询覆盖率 ≥ 95%，最长中断 ≤ 2 h（与第九阶段验收同口径） |
| 数据质量 | 行情正常占比 ≥ 99%；跨来源偏差暂停 ≤ 2 次；无 `quality_fault` 持续 > 6 h |
| 执行因果 | 时间顺序审计 T1–T8 零未决违规；fill 全部满足 决策 < 价格时刻 ≤ 执行 ≤ 记账 |
| 账本一致 | 费用 / 净值只读审计 0 问题；每日 nav 与成交重放一致 |
| 决策完整 | 每个已到的日线收盘恰有一次 signal 或 missed_signal；错过信号 ≤ 2 次且有原因 |
| 隔离 | 影子目录对 Mac 三账户目录零写入（哈希不变）；真实交易禁用 |
30 天不评价收益。

## 2. 90 天：信号表现初评（描述性）
- 报告每个账户：n 笔闭合交易、在场时间、扣费后净值、相对 BTC/ETH/50:50 的差额、最大回撤及持续时间、最大 5 笔占比。
- 行为观察（逐项回答是 / 否 / 无法判断）：是否捕捉到期内主要上涨段（定义：BTC 任意 30 日涨幅 ≥ 20% 的区间内平均暴露 ≥ 50%）；是否在期内主要下跌段（30 日跌幅 ≥ 20%）暴露 ≤ 50%；是否出现“退出后 10 日内以更高价格买回”（追高回补）≥ 2 次；是否出现连续 ≥ 60 日空仓且期间 BTC 上涨 ≥ 20%（无效空仓）。
- **n < 10 → 明确写“统计证据不足”**，不得宣称盈利能力。

## 3. 180 天：中期风险与收益
- 以上全部 + 回撤对比：策略最大回撤是否低于同期 BTC 持有；若低于，但同期暴露 < 30%，须标注“回撤低主要来自低仓位”。
- 扣费后相对 BTC 持有差额的符号与大小；成本占净值比例。
- 不同市场环境（期内按 BTC 90 日收益 ±20% 分类的月份）下的盈亏。

## 4. 365 天及以上：跨环境持续验证
- 至少经历一次牛市段与一次熊市 / 震荡段（按 §3 分类各 ≥ 3 个月），否则标注“环境覆盖不足”。
- 通过（可讨论扩大规模或进入下一阶段）的必要条件（全部满足）：
  1. 扣费后假设清仓净值 > BTC 持有净值，且最大回撤 < BTC 持有；
  2. 去掉最大 5 笔闭合交易后净利润仍 > 0；
  3. 30 天质量项持续通过（滚动）；
  4. 零因果违规、零账本不一致；
  5. 没有在前瞻期内改过参数。
- 任一不满足 → 继续观察或终止，不得宣称“已验证盈利”。

## 5. 报告禁止项
- 不填写尚未发生日期的任何数值；窗口未到期写“未到期”。
- 不把历史回测数字与前瞻数字放在同一列比较；页面与报告分区标注“历史回测 / 前瞻模拟 / 真实账户（无）”。
- 不写“保证”“稳定盈利”“月收益 X%”。
