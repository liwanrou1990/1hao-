## 2. 矿工现金生产成本模型（价格无关的“矿机代际”模型）
矿机表（发布日 / J/TH，墙插功耗 ÷ 标称算力）：
Avalon Gen1 2013-01-30 / 9,400；Antminer S1 2013-11-01 / 2,000；S3 2014-07-01 / 770；S5 2014-12-01 / 510；S7 2015-09-01 / 273；S9 2016-06-01 / 98；S15 2018-11-01 / 57；S17 Pro 2019-04-01 / 40；S19 2020-05-01 / 34；S19 XP 2022-07-01 / 21.5；S21 2024-01-01 / 17.5；S21 XP 2024-11-01 / 13.5。2013-01 之前的存量按 GPU / FPGA 计 500,000 J/TH。
规则（逐日，只用 ≤ t−1 的算力）：
1. 目标存量 = 算力 30 日均值。
2. 存量增加部分记入“当时已可交付（发布 + 90 天）的最新机型”（偏乐观 → 成本偏低，由区间高端覆盖）。
3. 存量减少时先移除效率最差的代际。
4. 效率劣于当时最新可交付机型 10 倍以上的代际视为淘汰，由最新机型等量替代；代际年龄满 5 年同样替换。
5. 机队效率 = 存量加权平均 J/TH；网络功率 = 算力 × 机队效率 × PUE 1.10。
6. 现金成本 / BTC = 日耗电 kWh × 电价 ÷ 日产出 BTC（区块补贴 + 手续费，CoinMetrics IssTotNtv + FeeTotNtv）。
7. 区间：低 = 效率 × 0.85 @ 0.04 美元/度；中 = 效率 @ 0.06；高 = 效率 × 1.30 @ 0.08。
8. 综合成本（含折旧与运营）= 中值现金成本 ÷ 0.6，**仅展示**，不进入规则。
9. 可信度：2014–2015 低；2016–2019 中；2020 → 中。没有外部真实数据可校准（CBECI 与矿企披露均不可得）。

**可靠性检查（决定实验是否“可验证”）**：(a) 与第十五阶段锚点模型在 2018–2026 的中值成本对数相关系数 ≥ 0.9，且中位数比值在 0.7–1.4 之间；(b) 中值成本全期为正且无跳变（日变化 > 50% 的天数 = 0，减半日除外）。任一不满足 → 依赖成本的实验（A / B / C / D / X1）全部标注“不可验证”，不报告交易结果。

## 3. 信号定义
- 成本比 r(t) = 第 t 日收盘 / 第 t−1 日中值现金成本。
- 周线：UTC 周一开始，周日收盘为周线收盘；20 周、40 周 SMA；周线信号只在周日收盘时更新，下一日开盘执行。
- 日线：SMA200、ATR14（第十一阶段口径）；日线结构检测器（第十一阶段，k = 3 分形；成交量为交易所报告成交量，不是主动买卖方向）。

## 4. 建仓实验（参数事先固定，不做选择）
“战役”：从空仓开始，战役资金 = 当时全部现金；每批 = 战役资金 × 比例。所有成交在信号次日开盘。
- **A 成本触及分批**：第一次 r ≤ 1.0 买 25%；此后每 14 天、只要 r ≤ 1.2 再买 25%，最多 4 批；若 r > 1.2 则暂停，再次 r ≤ 1.0 时继续。
- **A0 成本触及一次性**（对照）：第一次 r ≤ 1.0 买入 100%。
- **B 成本低估 + 周线趋势确认**：r ≤ 1.0 后“武装” 540 天；武装期内周线收盘 > 20 周 SMA 且 20 周 SMA ≥ 4 周前，买 50%；再满足 4 个周线收盘后若条件仍成立买剩余 50%。
- **C 成本低估 + 支撑 / 买盘确认**：r ≤ 1.0 后武装 540 天；武装期内第十一阶段回调确认、突破回踩或假跌破收复任一触发（含量比 ≥ 0.8），买 1/3，两次之间至少 7 天，最多 3 批。2015-07-20 之前无 OHLCV → 不可验证。
- **D 成本分层**：r ≤ 1.1、1.0、0.9、0.8 各触发一次，各买 25%（每个战役每层一次）。

## 5. 退出实验（不假设知道顶部；参数事先固定）
- **X1 成本高估分批**：r ≥ 2.0、2.5、3.0、3.5 各卖出战役峰值持仓的 25%。
- **X2 MVRV 过热分批**：MVRV ≥ 2.5、3.0、3.5、4.0 各卖 25%。
- **X3 周线趋势破坏**：出现过一次周线收盘 > 40 周 SMA 后，周线收盘 < 40 周 SMA 全部卖出。
- **X4 长期趋势减弱动态退出**：出现过周线收盘 > 40 周 SMA 后，周线收盘 < 20 周 SMA 卖 50%，周线收盘 < 40 周 SMA 卖剩余。
- **X5 长期持有 + 分批止盈**：价格达到持仓均价的 2、4、8、16 倍时各卖当前持仓的 20%；不设到期日，剩余永久持有。
战役在持仓清零后结束，剩余现金进入下一战役。组合 = {A, A0, B, C, D} × {X1…X5} = 25 个。

## 9. 必答问题的计算口径
- 成本区事件：r ≤ 1.0（另报 1.1 / 0.9 / 0.8）的连续区间，间隔 ≤ 60 天合并；每次记录首次进入日期与价格、此后 730 天内最低收盘的日期与跌幅、回到首次进入价的天数。
- 分批 vs 一次性：A vs A0、D vs A0 的平均成本与最终净值。
- 长期成本：战役平均成本 / 该周期最低收盘、/ 首次进入价。
- 卖出质量：卖出均价 / 两次成本区事件之间的最高收盘。
- 每笔交易记录：日期、价格、批次、触发规则与当时数值（r、MVRV、周线位置）、手续费、滑点、持仓天数、净利润。

## 10. 判定（事先写明）
