## 2. 架构与冻结规则
- **CoreTrendEngine**（候选核心，规则不改）：
  - `B2`：BTC+ETH，各自 `close > SMA200` 为 ON，等权分给 ON 资产，只在持有集合变化时调仓，`CircuitBreaker` 第六阶段参数（减仓 −10% → 50% 上限，熔断 −20% 全卖，冷静 / 恢复期）。= Phase 10 `B2_modelB_state_machine_daily_repro`。
  - `SMA200_dual`：同上无熔断（= Phase 10 S3）。`SMA200_btc`：仅 BTC（= Phase 10 S1）。
  - 核心目标仓位 = `core_frac` × 熔断允许上限 × 等权份额；`core_frac ∈ {1.0, 0.7, 0.5}`（事前登记变量，不预选）。
- **PullbackOpportunityEngine**：仅当该资产核心为 ON（已持有）且 Phase 11 策略 A 回调确认信号触发时，把该资产仓位从核心目标补到 `core_frac + opp_frac`（`opp_frac = 1 − core_frac`，即最多满仓）；**不要求上方存在已确认阻力 / 不设 1.5R 门槛**（Phase 11 拒绝原因审计结论），T1 若存在仅作记录；机会仓位的失效价 = A 信号给出的结构失效价。
- **BreakoutRetestEngine**：同上，用策略 B 突破回踩信号触发补仓。
- **StructuralExitEngine**（对全部持仓）：`trend_only`（只按核心规则退出）/ `structure_reduce`（收盘 < 最近已确认日线摆动低点 → 机会仓位全部退出、核心仓位减至 50%；核心在收盘重新 > 最近已确认摆动高点时恢复）/ `vol_trail`（收盘 < 最高收盘 − 3 ATR → 机会仓位退出、核心减至 50%，同样条件恢复）/ `t1_partial`（机会仓位触及最近已确认阻力区下沿卖出 50%、剩余按 structure_reduce）。
- **PositionAllocator / RiskController**：总暴露 ≤ 100%（熔断状态下 ≤ 其上限）；机会仓位合计 ≤ opp_frac × 权益；单笔机会仓位风险 ≤ `risk_pct ∈ {0.5%, 1%, 2%}` × 权益（按失效价距离换算，取与预算的较小者）；现金缓冲 0.1%，最小下单 10 USDT；无杠杆 / 做空 / 负现金。BTC/ETH 相关性 0.78 下不另设联合风险上限（已由总暴露与等权限制）。
- **SignalExplainer**：每次加仓记录市场状态（周线 / 日线 / 熔断状态）、已确认支撑区、预期入场区、失效价、预期卖出区或动态退出规则、扣费后潜在收益与风险（若有 T1）、资金占比、实际成交时间与价格；每日决策 BUY / ADD / HOLD / REDUCE / EXIT / WAIT 附理由。
