## 3. 因子定义（全部用 ≤ t−1 日数据；z 分数只用滚动历史窗口，不用全样本统计量）
BTC：
- `mvrv`：CapMVRVCur；`realized_price = PriceUSD / mvrv`。
- `puell`：IssTotUSD / 其 365 日均值（发行口径 Puell 倍数）。
- `hash_ribbon`：算力 30 日均 vs 60 日均；`capitulation = sma30 < sma60`；`recovery = sma30 上穿 sma60`。
- `miner_cost_ratio`：价格 / 估计电力现金成本中值。成本 = 算力(TH/s) × 机队效率(J/TH) × 86400 / 3.6e6 × 电价($/kWh) ÷ 日产出(BTC, 补贴+手续费)。机队效率锚点（对数线性插值）：2018-01 100、2020-01 60、2022-01 38、2024-01 30、2026-01 22 J/TH；电价 0.04–0.08 $/kWh 给区间，中值 0.06。**这是假设驱动的区间，不是价格底部。**
- `halving_phase`：自上次减半的天数 / 1458，∈[0,1+)。仅作背景标签与一个门控实验，不作为涨跌规律。
- `ex_netflow_30d`：30 日 Σ(FlowInEx − FlowOutEx) / SplyCur；`ex_supply_chg_90d`：SplyExNtv 90 日变化率。
ETH：
- `mvrv`、`realized_price` 同上。
- `ethbtc_rs`：PriceBTC（ETH/BTC）相对其 200 日均值的偏离；`ethbtc_mom_90`。
- `net_issuance_30d`：30 日净发行（供应量日差；2021-08 前 = IssTotNtv）/ SplyCur。
- `ex_netflow_30d`、`ex_supply_chg_90d` 同上。

## 4. 策略集合（时间顺序：训练 2018-01-01→2021-12-31 选参 → 验证 2022-01-01→2023-12-31 确认 → 样本外 2024-01-01→最新 仅评估一次）
基准（固定，与第十阶段一致）：BH_BTC、BH_ETH、BH_5050、S1 BTC_SMA200、S2 ETH_SMA200、B2 模型 B + 熔断状态机。
  - 【事后澄清，2026-11-10，首次回测前的基准复现检查时发现】第十阶段的 S1/S2 带 20% 风险退出，而 Mac 账户 A / REF 对应的是第十阶段 B1/B3（无风险退出）。本阶段基准采用 B1_BTC_SMA200 / B3_ETH_SMA200（与 Mac 账户规则一致），代码中 S1/S2 名称相应改为 B1/B3；数值与第十阶段 B1/B3 逐位一致（测试断言）。此改动发生在任何因子结果产生之前，不影响因子规则。
单因子（factor_only：入场 / 退出都只由该因子决定；网格 ≤ 6 组）：
- F1 MVRV 区间（BTC、ETH 各一）：入场 mvrv < a，a∈{1.0, 1.2}；退出 mvrv > b，b∈{2.5, 3.0, 3.5}。
- F2 Puell（BTC）：入场 puell < a，a∈{0.5, 0.6, 0.8}；退出 puell > b，b∈{2.5, 4.0}。
- F3 算力带（BTC）：入场 = recovery（30 日均上穿 60 日均）；退出 = capitulation 开始。无参数。
- F4 矿工成本比（BTC）：入场 ratio < a，a∈{1.0, 1.2}；退出 ratio > b，b∈{3, 4}。
- F5 ETH/BTC 轮动（ETH 仓位）：ethbtc > 200 日均 → 持 ETH，否则持 BTC（单因子，无参数）。
- F6 交易所净流（BTC）：入场 ex_netflow_30d 的 365 日滚动 z < −1；退出 z > +1。无参数。
组合（估值背景 = 门控；趋势 = SMA200；入场执行 = 次日开盘；禁止单一因子直接 BUY）：
- C1 BTC_SMA200 + MVRV 门控：只有 mvrv < g 时允许新入场，g∈{2.0, 2.5, 3.0}；趋势关闭 **或** mvrv > 3.5 退出。
- C2 B2 + 双资产各自 MVRV 门控（g 同上，共用一个 g）。
- C3 BTC_SMA200 + 算力带门控：仅 sma30 ≥ sma60 时允许新入场。无参数。
- C4 BTC_SMA200 + Puell 门控：puell < 3 允许入场；puell > 4 退出。无参数。
- C5 BTC_SMA200 + 综合估值分（mvrv、puell、miner_cost_ratio 各自 4 年滚动 z 的均值）< g，g∈{0, 0.5, 1.0}。
- C6 ETH_SMA200 + ETH/BTC 相对强弱门控（ethbtc > 200 日均）+ MVRV 门控（mvrv < 2.5）。无参数。
- C7 C2 + 日线结构门控（第十一阶段 DailyStructureDetector：收盘 > 最近已确认摆动低点才允许新入场）。无参数。
- H1 BTC_SMA200 + 减半阶段门控：仅 halving_phase < 0.75 允许新入场（实验，预期证据不足）。无参数。

选参规则：对每个有网格的策略，**只用训练段**按 15 bps 假设清仓净收益选最优；在验证段必须同时满足“净收益 > 对应 SMA200 基准”才算确认；样本外对确认过的参数只跑一次并报告；同时**公开**网格全部样本外结果（只作稳健性展示，不用于选择）。不得按样本外结果回头改网格。

## 5. 成本与执行
单侧 15 bps（滑点 5 + 手续费 10，与 Mac 账户一致）为主；0 与 25 bps 为敏感性。次日开盘成交；买入资金 = 目标权重 × 权益，现金缓冲 0.1%，最小下单 10 USDT；因子门控只影响“是否允许新入场 / 是否强制退出”，不改 SMA200 参数。

## 6. 输出指标（每策略 × 窗口 × 成本）
期末权益与假设清仓净收益、CAGR、最大回撤与最长回撤期、成交笔数与闭合交易数、空仓比例（1 − 在市时间）、平均 / 中位持仓天数、手续费 + 滑点合计（换手成本）、相对 BH_BTC / BH_ETH / BH_5050 的超额、牛 / 熊 / 震荡月份盈亏（第十阶段口径：BTC 90 日收益 ±20%）、证据充分性。

## 7. 判定（事先写明）
- 某因子“确实改善样本外”：组合策略在样本外 15 bps 下假设清仓净收益 > 对应无因子基准，**且**最大回撤不劣于基准，**且** 0 / 25 bps 下方向一致，**且**训练、验证段同样为正改善。缺任一条 → “未改善”或“证据不足”。
- 闭合交易 < 10 笔的策略一律标“证据不足”，无论收益。
- 单因子策略不作为可执行信号候选（预登记禁止单因子 BUY），只用于理解因子行为。
- “是否纳入下一阶段前瞻观察”：仅当至少一个组合因子通过上述判定且在三个窗口方向一致，才建议作为**观察因子**（不执行）进入第十三阶段影子系统；否则判“不采用”。
