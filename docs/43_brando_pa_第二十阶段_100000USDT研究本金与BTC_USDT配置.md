## 0. 结论

**在 100,000 USDT 初始本金、最大回撤研究预算 50% 的条件下：**

1. **历史风险收益最好的固定配置是“25% BTC + 75% USDT，每年 1 月第一个交易日再平衡”（ALLOC_25_Y）。**
   2014-01-01 → 2026-11-07：100,000 → **1,526,469 USDT**（净利润 1,426,469），年化 23.6%，最大回撤 **−39.7%**，收益回撤比 0.60。全样本、5 个压力区间、36 个滚动 4 年起点的最大回撤**都没有超过 50%**（最差 −39.7%），只触及过 35% 预警线。
2. **没有足够证据证明它（或任何预算内的配置）优于 BTC 简单买入持有——以最终 USDT 计明确劣于买入持有。**
   同期买入持有 100,000 → **9,974,359 USDT**，是 25% 配置的约 6.5 倍；三个分段窗口中 25% 配置 0 个超过买入持有，36 个滚动起点中 0 个超过。它的优势只在**回撤**：买入持有最大回撤 −83.2%，100% 的 4 年起点都跌破过 −50%。
3. 两个需要知道的旁证：
   - **50% BTC 年度再平衡**收益回撤比更高（0.65，最终 5,416,554），但全样本最大回撤 −55.6%，36% 的 4 年起点超过 50%，2014 熊市 −50.3%，**不在预算内**。
   - **原 B2（只有 2017 年起的数据）**风险调整后最好：2017 → 最新 1,418,086，最大回撤 −24.1%，收益回撤比 1.28（同期 25% 年度再平衡 1,228,689 / −39.6% / 0.73）。但它只能从 2017 年起比较，不能与 2014 起的全样本直接比。
4. 100,000 USDT 真实重算与“10,000 结果 ×10”不同：低频配置差异很小（−0.4%），交易频繁的 SMA200 少了 **9.0%**（约 94 万 USDT），主要是流动性冲击随订单规模按平方根增长。

## 10. 事后说明与限制

- **事后（完整运行之前）**：配置引擎原先在窗口首日开盘建仓，与其他引擎“首日收盘决策、次日开盘成交”不一致，导致 100% 配置 ≠ 买入持有。改为次日开盘建仓（预登记 §7）。
- **事后（运行时缺陷修复）**：滚动起点日期生成的时区参数错误导致报错，修正为带时区的起点；不改变方法。
- 压力区间是事后按已知历史选的，只作观察。
- 2014-01 → 2015-07-19 只有收盘价、没有成交量：这段的成交按 25 bps 冲击，回撤按收盘价计算（低估盘中回撤）。
- 冲击模型是简化的平方根模型（系数 1.0、上限 100 bps），没有用真实订单簿验证；成交量为交易所报告量。
- USDT 不计利息，也没有计入 USDT 本身的脱锚风险。
- 50% 是研究预算，不是止损。历史回撤 −39.7% 不代表未来不会更深。
- 收益回撤比的比较只作描述，没有统计显著性检验；样本只有约 3 个完整牛熊周期。
