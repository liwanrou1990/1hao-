## 1. 数据与方法

- 数据：BTC/ETH 日线 2017-08-17 → 2026-11-07（最新已收盘），3,370 根/币，无缺口、无重复、OHLC 合法；来源 Binance 现货静态镜像 3,369 根 + OKX 现货最新 1 根；与 OKX 日线最近 401 天交叉比对：收盘价相对偏差中位数 0.5 bps，最大 8 bps（BTC）/ 19 bps（ETH），只记录不修正。2017-08 → 2017-12 仅用于 SMA200 预热。
- 时间规则：第 t 日收盘后决策（只用 ≤ t 的收盘），第 t+1 日开盘成交；净值按收盘标记。单元测试验证篡改未来价格不改变过去任何决策与成交。
- 成本：单侧 0 / 10 / 15 / 25 bps（滑点固定 5 bps + 手续费），买卖均扣；买入持有同口径（入场一次 + 期末假设清仓一次）。
- 窗口：全样本 2018-01-01 → 2026-11-07；训练 2018–2021；验证 2022–2023；样本外 2024-01-01 → 2026-11-07；逐年独立起算。无参数搜索（SMA200、确认 1 日、风险退出 −20%、30/60/90 全部预先固定）。
- 期末拆分：已实现净额（闭合交易净盈亏 − 全部买入手续费）、未实现（期末收盘标记）、假设清仓净收益（再扣卖出成本）。恒等式“权益 − 初始 = 已实现净额 + 未实现”每行校验。

- 固定持有期（到期强制卖出、次日趋势仍在就再买入）制造了大量无信息的往返：30 天版本 428 笔成交，25 bps 下成本 16,041 USDT，从 0 bps 到 25 bps 收益减半。它在 0 bps 下“最好”只是因为周期性再平衡在无成本时等价于频繁加减仓。
- 60 与 90 天版本在全样本甚至低于 BTC 买入持有，且最大回撤与买入持有相当（−80%）。
- “最短持有后按趋势退出”（S7、X_MINHOLD30/60）才真正减少了成交（87–101 笔 vs 65 笔的纯 SMA200 却持仓更久），成本最低（S7 总成本 3,783），全样本接近 S1，样本外略好于 S1。
- 结论：**“持有 N 天”本身不是收益来源；减少 SMA200 的短期来回止损才是。固定到期卖出有害，最短持有期无害但也不显著更好。**

## 6. 结论与建议（不做盈利承诺）

1. **历史上 SMA200 趋势持有盈利，但其优势是“熊市少亏”，不是“牛市多赚”**；2024–2026 的样本外它没有跑赢持有 BTC。8.8 年只包含约两个完整周期，统计证据薄弱。
2. **固定 30 / 60 / 90 天持仓不可取**：到期强制卖出增加成本、减少趋势持有时间；最短持有期（S7、X_MINHOLD60）能把成交从 65–174 笔降到 87 笔，成本降一半，收益与纯 SMA200 相当，但没有达到预登记的“全部窗口一致优于买入持有”。
3. **不建议为本阶段新开 30 天前瞻账户**：这些策略每年 2–6 次信号，30 天几乎不会产生可评估的交易。现有三个 Mac 账户继续运行即可；如要延续本阶段，建议把 S7 与 X_MINHOLD60 作为“只记录、不交易”的影子信号加入前瞻日报，等待至少一个完整趋势周期。
4. 风险提示：BTC/ETH 是事后已知存活的两大币种，所有策略与买入持有的收益都含生存者偏差；最大回撤 −65% 到 −80% 对实际资金是不可接受的，B2 状态机（−25.5%）是唯一回撤可控的版本，但其样本外收益最低档。
