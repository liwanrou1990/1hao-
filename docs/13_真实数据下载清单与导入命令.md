# 13 · 真实数据下载清单与导入命令（目标日 2026-10-22）

本环境对 bitget 全部域名 403/不可达，**不能在这里下载**；以下为本地浏览器/本地机器可直接执行的清单与命令。导入后系统按来源自动分级，缺少逐笔或深度时不会提级。

## A. 第一批（先验证）：BTCUSDT、ETHUSDT、SOLUSDT + 可取得真实成交数据的 rToken
| # | 资产 | 场所 | 需要的文件（2026-10-22，America/New_York 自然日 ⇒ UTC 2026-10-22 04:00 ~ 2026-10-23 04:00） | 来源 |
|---|---|---|---|---|
| 1 | BTC | Bitget 交易所现货 BTCUSDT | 1 分钟 K 线、成交历史（逐笔）、深度 | 官方下载中心 https://www.bitget.com/data-download（现货 K 线/成交/深度）；或公开 API（脚本） |
| 2 | ETH | ETHUSDT | 同上 | 同上 |
| 3 | SOL | SOLUSDT | 同上 | 同上 |
| 4 | NVDA | Bitget 交易所 rToken 现货 rNVDA/USDT | 1 分钟 K 线、成交历史；深度若有 | 下载中心是否含 rToken 待核对；公开 API：`history-candles` / `fills-history`（symbol 格式候选 rNVDAUSDT / RNVDAUSDT） |
| 5 | TSLA | rTSLA/USDT | 同上 | 同上 |
| 6 | SPY / QQQ | rSPY、rQQQ | 同上 | 同上 |
| 7 | HYPE | HYPEUSDT（是否上架需核对） | 同上 | 同上 |
| — | xStocks / Ondo 链上代币 | Bitget Wallet | ToB API `kline`/`transactionList`（需放行 bopenapi.bgwapi.io）或链上成交导出（声明 chain+contract） | 第二批 |

**下载中心核对要点**：日期范围是否覆盖 2026-10-22（注意 UTC 跨两天，需下载 10-22 与 10-23 两个 UTC 日文件）；K 线粒度 1 分钟；成交历史为逐笔；深度文件的快照频率与档位数；文件名与列头原样保留（导入器按列自动识别）。

## B. 目录与导入命令
```
data_in/
  BTC/2026-10-22/   kline_*.zip|csv  trades_*.zip|csv  depth_*.zip|csv
  ETH/2026-10-22/   ...
  SOL/2026-10-22/   ...
  NVDA/2026-10-22/  kline_*.csv trades_*.csv  meta.json  ← {"venue": "bitget_spot", "pair": "rNVDAUSDT"}
```
```bash
# 1) 导入（文件名以 kline/trades/depth 开头可直接识别；否则按列自动识别；zip 内多文件自动拼接；UTC 两天文件可同时放入，按美东自然日过滤）
bgwq import-dir --day 2026-10-22
# 或单文件：
bgwq import-csv --kind kline  --symbol BTC  --file data_in/BTC/2026-10-22/kline_BTCUSDT_2026-10-22.zip
bgwq import-csv --kind trades --symbol BTC  --file data_in/BTC/2026-10-22/trades_BTCUSDT_2026-10-22.zip
bgwq import-csv --kind depth  --symbol BTC  --file data_in/BTC/2026-10-22/depth_BTCUSDT_2026-10-22.zip
bgwq import-csv --kind kline  --symbol NVDA --venue bitget_spot --pair rNVDAUSDT --file data_in/NVDA/2026-10-22/kline.csv
# 列名不识别时显式映射：--map ts=open_time,open=o,high=h,low=l,close=c,volume=v,amount=quote_volume

# 2) 完整性与分级（来源、时间范围、K 线覆盖、缺口、逐笔分钟覆盖、深度覆盖、场所匹配）
bgwq data-status --day 2026-10-22
bgwq venue-check --day 2026-10-22

# 3) 严格模式重算（任一资产非真实即终止）；先只跑第一批资产
bgwq playbook-daily --day 2026-10-22 --no-ingest --require-real --symbols BTC ETH SOL NVDA
# 4) 参与率敏感性（1% / 5% / 10%）
bgwq playbook-sensitivity --day 2026-10-22 --symbols BTC ETH SOL NVDA --participations 0.01 0.05 0.10
```
公开 API 抓取脚本（有网络的机器）：`python scripts/fetch_bitget_public.py --symbols BTCUSDT ETHUSDT SOLUSDT rNVDA rTSLA --day 2026-10-22 --out data_in`（rToken 自动尝试交易对候选并写 meta.json；深度只能当天实时采样 `--depth-seconds 60`）。

## C. 输出
`reports_out/playbook/2026-10-22/<分级>/`：总览 HTML、流水 CSV（逐笔含分钟成交额与占用比、深度结论、校验标记）、校验 CSV、敏感性 CSV/MD、JSON；`reports_out/charts/playbook_<档位>_2026-10-22_<分级>_*.html`（K 线买卖点 + 收益曲线）；`playbook_compare_2026-10-22.md`（SIMULATED / EXECUTION_ESTIMATED / REAL_HISTORICAL 三组并排，缺的一组写“无数据”）。
