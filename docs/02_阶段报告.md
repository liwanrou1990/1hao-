# 02 · 阶段报告（开发顺序与自动化测试结果）

执行环境：Claude Code 云容器，2026-10-19。数据模式：**SIMULATED**（无密钥、官方主机被网络策略拒绝，见 00 报告）。所有数字均来自模拟数据与成本假设，仅证明流水线正确，不代表真实行情。

## 阶段 0：环境检查与接口文档
- 完成：Python/Node/依赖检查；官方 SDK 源码确认接口路径、参数、返回字段、签名算法；网络/密钥阻塞如实记录。
- 产出：`docs/00_环境与接口检查报告.md`。

## 阶段 1：数据与标的（12 项测试通过）
- 签名实现与官方 TS 算法参考向量一致；无密钥 probe 返回 `blocked=True`，不伪装成功；MockTransport 验证 stockList/kline 解析及 ondo 无成交量标记；Massive 行只保留常规时段并拒绝周末；日历拒绝周末/假日，黑五早收盘 210 根；模拟源确定性、带 SIMULATED 标记、拒绝非交易日；代币 venue 与原生分开；质量位与 research_ready；DuckDB 幂等写入；SPCX 不可交易；auto 模式无密钥退回 simulated 且 live 强制模式报错。

## 阶段 2：成本模型与双模式复盘（18 项测试通过）
- 成本模型缩放/拆单/不可验证标记；成交价含费；成交失败仍付 Gas；DP 结果与 12 根 K 线暴力枚举完全一致；高成本时 DP 输出 0 笔；B 模式在信号下一根开盘成交、日终空仓、收盘前 5 根无仓位、多日不跨日；9 个策略前缀一致性（反未来函数）全部通过，故意偷看下一根的策略被检出；A/B 对照与 K 线 HTML 生成。
- NVDA 2026-10-16（模拟，token_dex，本金 10,000）：A 最优 +4.53%（2 笔），最佳 B（VWAP）+0.55%（2 笔），差距 +3.98%；差距解释自动生成。

## 阶段 3：策略与机器学习（6 项测试通过）
- 9 类策略注册；无成交量字段时成交量策略不交易；特征因果；标签不跨日且与手算一致；切分拒绝过短训练窗、embargo 正确；walk-forward 测试集严格在训练集后，记录市场环境分布；阈值为 None 的模型必然输出不交易；`has_edge` 要求 CI 下界 > 0。
- 结果（NVDA 模拟 70 日，token_dex）：5/15/30/60 分钟 OOS AUC ≈ 0.67/0.56/0.52/0.49，但扣费后交易时平均净收益无正期望 → 四个周期全部"不交易"。

## 阶段 4/5：本金分层与严格回测（9 项测试通过）
- 七档读取并标记：计息口径未知、周期单位未知、缺档 5,000–19,999、重叠 50,000–99,999；重叠本金命中两档；容量表 21 行，≥100 万美元全部"不可验证"；达标率在均值低于下限时显示"未达标"；指标字段完整；基准含无交易=0；walk-forward 样本外窗口严格在训练窗之后；成本门减少交易且因果；7 个压力情景运行且成本加倍不优于基准。
- NVDA 模拟 70 日（token_dex，样本外）：9 个规则策略日均净收益均为负（−1.8% ~ −25.9%），买入持有 −1.2%，无交易 0，理论最优 +2.2%/日；七档目标达标率全部 0% → **未达标**。

## 阶段 6：工作台与日报（6 项测试通过）
- API：status/symbols/rankings/bars/replay/trades/backtest/stress/tiers/capacity/attainment/ai/training/report/reports；训练流程 start→decide→advance→finish→leaderboard；快速日报 HTML/CSV 可下载。
- 前端：Vite 构建通过，Playwright 截图核验六个页签（行情排名、复盘与交易、回测/本金容量、AI 信号、训练模式、日报）。
- 已知限制：PDF 需安装 weasyprint；DuckDB 单写者——`bgwq serve` 运行时 CLI 不能同时打开同一数据库（改用 `/api/report` 或另设 `BGWQ_DB_PATH`）。

## 阶段 7：执行安全（含于上述 6 项）
- `research_only` 固定；非研究模式被强制回退并审计；任何下单调用抛出 `ExecutionForbidden`；疑似私钥环境变量仅告警不读取。

## 阶段 8：事后最优交易路径（核心需求，6 项测试通过）
- DP 与暴力枚举一致（含人为低流动性 K 线）；交易次数受限 DP 单调且与暴力一致；全日约束校验（不超本金、不超逐根流动性、区间不重叠、利润恒等式）；目标不可达时 `target_met=False` 且无达标路径；流动性未知标记不可验证；组合轮动 ≥ 最佳单股且跨股票不重叠、并行均分不超本金。
- NVDA 2026-10-16（模拟代币 K 线，token_dex）：T1（1,000–4,999）最高可实现约 +5.5%~+5.8%（3 笔），0.8% 目标 1 笔即可达标；T2/T3 下限~中位 达标；≥ 299,999 USD 起受逐根流动性上限（单笔最大投入约 58,616 USD）限制，最高可实现收益降至 0.6% 以下，T3 max 至 T7 全部**未达标**（显示最高可行收益）。
- 全标的 × 七档 + 组合日报 12.6 秒生成：`reports_out/2026-10-16/hindsight_report_2026-10-16.html`、`hindsight_trades_2026-10-16.csv`（393 行）、每标的可切档位的 K 线图。

## 阶段 9：固定收益目标 · 多次交易 · 稳定性优先（7 项测试通过）
- 目标取值规则（重叠/缺档）；分批成交逐根流动性上限与部分成交；教学路径约束（不加杠杆、单笔净收益≥目标、MAE≤止损、同一时刻单持仓、累计恒等式、达标即停）；目标不可达如实报告；策略前缀一致性（无未来信息）；日内风控（次数上限、亏损上限）；滚动样本外结构。
