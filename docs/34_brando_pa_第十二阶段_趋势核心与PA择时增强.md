逐条结论：
1. **“T1 必须来自已确认阻力且 ≥1.5R”是唯一起决定作用的过滤器**：204/223 因此被拒；量比、收盘位置、缩量只在“等待确认”层面起作用（209 个近似候选），与 T1 规则不重叠，不存在重复过滤。
2. **创新高 / 阻力带内行情被系统性排斥**：80% 的候选处于最高阻力带内部或上方（≤ 2 ATR），此时按定义不存在“上方已确认阻力”。
3. **结构失效价、ATR 与风险预算耦合过紧**：失效价中位距离 13.5%，1% 风险 → 仓位 ≈ 7–10%，即使全胜也无法接近满仓趋势系统。
4. **买盘确认与突破确认不重复**：A 用回调 + 缩量 + 确认日，B 用突破 + 回踩 + 企稳，候选集几乎不相交（A 55 / B 168）。
5. **PA 阻止了核心持仓**：100% 的候选发生在核心已持仓时；Phase 11 把 PA 作为唯一入场条件等于放弃核心的 50% 在场时间。Phase 12 据此把 PA 改为只做加仓 / 退出增强。
6. 各过滤器边际影响见 §4 的 core_frac / 扰动表：PA 加仓触发 20–53 次、机会仓位平均暴露 2–10%，对净利润的边际贡献为负或接近零。

## 5. 为什么增强没有帮助（机制诊断）

1. **core_frac < 1 直接削掉收益来源**：B2 的收益来自 2019-04 → 2021-05、2023-10 → 2024-07 等少数长持仓；把核心降到 70% / 50% 就少了 30–50% 的参与，而机会仓位需要 PA 触发才补上，20–53 次触发平均只贡献 2–10% 暴露，补不回来。
2. **结构减仓 / 再入场是双向成本**：收盘跌破最近已确认摆动低点时减半、重新突破摆动高点时恢复，在 2021-H2、2024-H2 等震荡段反复发生，E_structure_reduce 比 A 少 21,000 USDT，回撤未改善（回撤由熔断决定）。
3. **波动跟踪（3 ATR）只在部分时段减少回吐**，全样本仍少 6,000；回撤不变。
4. **突破回踩加仓（D）是增强组合中最好的**，因为它在 2021 与 2023 的突破后追加了仓位；但它仍是“在 70% 核心基础上补回部分仓位”，净效果低于直接 100% 核心。
5. **回撤 −25% 的来源是熔断状态机**（−20% 权益回撤全卖 + 冷静期），PA 层没有改变这一机制，所以 E/F 的回撤与 A 几乎相同；回撤更低的配置只是仓位更低。

## 7. 下一步建议（不是结论）

1. 停止在 2018–2026 上继续叠加 PA 层；现有证据不支持“PA 择时能改善 B2 / SMA200”。
2. 若要降低 B2 的 −25% 回撤且不牺牲参与度，值得研究的是熔断状态机本身的参数（减仓 / 熔断阈值、冷静期），但这属于修改受保护的核心规则，必须另行预登记并只用前瞻数据评估。
3. 保持 Mac 三个账户继续运行（72 小时验收进行中），它们就是 A 与 B 的真正样本外。
4. 如果一定要保留 PA 模块，用途应是解释与监控（当前趋势 / 支撑区 / 失效位 / 下一目标区的只读页面），而不是改变核心仓位。
