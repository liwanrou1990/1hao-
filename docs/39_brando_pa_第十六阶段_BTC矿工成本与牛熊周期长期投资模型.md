### 1.1 成本模型与事后修正

模型：逐日跟踪“矿机代际”存量（目标 = 30 日平均算力；新增算力记为当时已可交付的最新机型；下降时先移除效率最差的；劣于最新机型 10 倍或满 5 年的替换为最新机型）；网络功率 = 算力 × 机队效率 × PUE 1.10；现金成本 = 日耗电 × 电价 ÷ 日产出；区间 = 效率 ×0.85 @ 0.04 / ×1 @ 0.06 / ×1.3 @ 0.08 美元每度。

**预登记原版未通过自己的可靠性检查**：与第十五阶段独立模型对数相关 0.995、中位数比 0.89 通过，但有 4 个单日跳变 > 50%（2014-01-02、2017-08-24、2017-10-27、2021-04-16）。原因是分子用 30 日平均算力、分母用逐日产出，而日出块数波动 ±40%。

**事后修正**（在任何策略代码与回测之前决定，只看成本序列本身）：分母改为“30 日平均出块数 × 当日协议补贴 + 30 日平均手续费”，减半当天成本即时翻倍。修正版：对数相关 0.992、中位数比 0.90、跳变 0 天。所有成本实验结果都基于这个修正版。

当前读数（2026-11-10）：现金成本区间 27,066 – 82,790，中值 47,763；机队效率 13.5 J/TH（模型假设新增算力全是最新机型，偏乐观，所以近年成本可能偏低）。

## 2. 预登记的实验

建仓（战役资金 = 当时全部现金，次日开盘成交）：A 首次价格 ≤ 成本中值买 25%，此后每 14 天、只要 ≤ 1.2 倍再买，最多 4 批；A0 首次触及一次性买入；B 成本低估后等周线收盘站上 20 周 SMA 且 SMA 上行，分两批；C 成本低估后等第十一阶段的支撑 / 回踩 / 收复确认，分三批；D 价格 / 成本 ≤ 1.1、1.0、0.9、0.8 各买 25%。
退出：X1 价格 / 成本 ≥ 2.0、2.5、3.0、3.5 各卖 25%；X2 MVRV ≥ 2.5、3.0、3.5、4.0 各卖 25%；X3 出现过周线站上 40 周 SMA 后跌破即全卖；X4 跌破 20 周卖一半、跌破 40 周卖剩余；X5 价格达到均价 2、4、8、16 倍各卖 20%，剩余永久持有。
对照：BTC 买入持有、BTC SMA200（B1，与 Mac 账户 A 同规则）、B2（需要 ETH，只能从 2018 年起）。
成本：单边 0 / 10 / 25 / 50 bps（往返 0 / 20 / 50 / 100 bps），买卖两侧都扣，期末再按假设清仓扣一次。
时间：训练 2014–2017、验证 2018–2021、后段检验 2022 → 最新（**非盲测**：2024–2026 已在第十至十五阶段被反复研究）；另按减半周期独立起算。**不做任何参数选择。**
规模：8 个窗口 × 4 档成本 × 28 个策略 = 880 次回测。

实现细节（未改变规则含义）：战役进入卖出阶段后不再买入；B 第二批买入剩余战役资金；同一天触发多个 X5 倍数时依次各卖当前持仓的 20%。

## 3. 必答问题

**1. 历史上多少次跌到矿工成本附近？**（成本区事件：价格 / 成本连续低于阈值，间隔 ≤ 60 天合并）

| 阈值（价格 / 成本中值） | 次数 | 首次进入日期 |
|---|---|---|
| ≤ 1.1 | 4 | 2015-01-14、2018-11-20、2020-03-12、2022-11-21（仅 1 天） |
| ≤ 1.0 | 3 | 2015-01-14、2018-11-24、2020-03-12 |
| ≤ 0.9 | 2 | 2015-01-14、2018-12-06 |
| ≤ 0.8 | 0 | — |

口径敏感性（同为价格 ≤ 成本）：用低端成本 0 次；用高端成本 10 次（2014-09、2016-01、2016-07、2018-09、2019-09、2022-06、2024-04、2025-02、2025-11、2026-10）；用第十五阶段模型（2018 →）5 次，且与本模型几乎不重合。

**2–3. 进入成本区后最长继续下跌多久、最大继续下跌多少？**
- 主口径（≤ 1.0）：2015 与 2020 首次进入当天就是此后两年最低收盘；2018 年继续下跌 **21 天、−18.3%**（3,932 → 3,212）。≤ 1.1 口径：2018 年继续下跌 25 天、−29.5%。
- 高端成本口径：继续下跌最长 **490 天**（2025-02 起），最大 **−53%**（2014-09 起），−52%（2018-09 起）。
- 结论：“跌到成本附近就是底”在主口径下看起来很准，但只有 3 次，且换一个同样合理的假设就完全不成立。

**4. 成本附近分批买入比一次性买入更好吗？** 历史上**一次性更好**：同样的退出规则下，A0（一次性）全样本净收益在 5 种退出中全部高于 A（分批）和 D（分层），例如 X4：A0 242,095 / D 148,542 / A 55,012。原因是 3 次首次触及中有 2 次恰好是最低点，而分批规则在价格反弹超过 1.2 倍后暂停，大量资金没有投入。这不能推广：在高端成本口径下首次进入后又下跌 40–53%，那种情况分批会更好。

**5. 不预测最低点能否拿到较好的长期成本？** 在这 3 次事件里可以：A0 的平均建仓成本 / 周期最低收盘 = 1.00（2015）、1.23（2018）、1.00（2020）。B（等周线确认）要贵得多：1.42、2.05、1.91 倍；C（等支撑确认）1.43、1.17、1.54 倍。但 2022 年熊市（低点约为成本的 1.09 倍）主口径完全没有建仓，等于错过了整个 2023–2025 行情。

**6–7. 每轮牛市用什么条件卖出更合理、卖不到顶部还剩多少？**（卖出均价 / 两次成本区事件之间的最高收盘）

| 退出 | 表现 | 卖出均价 / 周期顶部 |
|---|---|---|
| X1 成本高估 | 回撤最小（全样本 −15% 到 −32%），但 2017 年卖得太早 | 0.04（2017）、0.76（2019）、0.16–0.30（2021） |
| X2 MVRV 过热 | 全样本净收益最高，但 2021 年 MVRV 最高 3.96 未达 4.0，最后 25% 一直未卖，回撤 −51% | 0.29（2017）、0.21（2021 后，含未卖部分） |
| X3 周线跌破 40 周 | 2018–2021 最好之一；2015 年因假突破过早离场，错过 2016–2017 | 0.01（2015）、0.53（2019）、0.28（2021） |
| X4 周线跌破 20 / 40 周 | 验证段最好（A0_X4 149,660） | 0.01（2015）、0.57（2019）、0.33–0.60（2021） |
| X5 长期持有 + 倍数止盈 | 回撤最深（−73% 到 −77%） | 大部分持仓从未卖出 |

没有任何一种退出在所有周期都占优。即使只卖在顶部的 20–60%，因为建仓在低位，单个战役仍可获得数倍收益（例：A0_X4 2020 年 4,805 买入、40,544 平均卖出），但这些都是事后已知的三次周期。

**10. 为什么没有新增优势？**
1. **成本区太少且依赖假设**：主口径 12 年 3 次，最近一次是 2020 年 3 月；低端 / 高端假设下是 0 次 / 10 次。
2. **最近一轮熊市没有跌到模型成本以下**（2022-11 低点约为成本的 1.09 倍），这类策略在 2022 → 2026 完全空仓。模型假设新增算力都是最新机型，近年成本可能被低估，这又是一个无法用真实数据校准的假设。
3. **样本中的成功高度集中**：3 次事件中 2 次首次触及就是最低点，全样本的巨大收益几乎都来自 2015 和 2020 两个起点。
4. **资金闲置**：成本类策略 64–86% 的时间持有 USDT。
5. **潜在的事后知识**：模型不用价格，但矿机表、电价与 PUE 都是今天整理的，无法证明当时的研究者会选同样的数。

## 4. 判定（预登记 §10）

- “新增优势”要求验证段与后段检验、10 与 25 bps 都同时高于 BTC 买入持有与 BTC SMA200，且回撤不劣于买入持有。**25 个组合全部不满足**，主要因为后段检验中没有交易或收益低于 SMA200。
- 证据充分性：全样本闭合战役最多 4 个 < 5 → 无论结果，都只能称“周期样本极少，不能证明稳定规律”。
- **结论：不采用；不进入真实前瞻执行。** 按预登记，从 2026-11-10 起建立独立前瞻观察日志 `data_store/brando_pa/phase16_minercycle/forward_observations.jsonl`（只记录读数，哈希链，不产生订单）。追加一条：`PYTHONPATH=src python3 -m brando_pa.pa16.current16`（手动运行，不是常驻服务）。
