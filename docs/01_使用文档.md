# 01 · 使用文档（本地运行）

## 安装

```bash
git clone <本仓库> && cd 1hao-
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"            # 可选 PDF：pip install -e ".[pdf]"（需系统安装 weasyprint 依赖）
cp .env.example .env               # 填写密钥；无密钥时自动进入 SIMULATED 模式
cd frontend && npm install && npm run build && cd ..
```

## 常用命令（`bgwq --help`）

| 命令 | 作用 |
|---|---|
| `bgwq probe` | 探测 Bitget RWA 与 Massive：权限、单次 K 线返回跨度、延迟/限频、成本提示；无密钥时输出阻塞项 |
| `bgwq ingest --days 70` | 接入最近 70 个美股交易日的分钟 K 线（原生 venue + 代币 venue），写入 DuckDB |
| `bgwq replay NVDA [--day 2026-10-16]` | 双模式复盘：A 事后最优（DP）vs B 当时可执行（13 个策略），输出差距解释与 K 线图 HTML |
| `bgwq backtest NVDA` | 规则策略 walk-forward 样本外验证 + 基准 + 七档达标率 |
| `bgwq train-ml NVDA` | LightGBM 5/15/30/60 分钟模型（purged walk-forward、校准、阈值、CI） |
| `bgwq report [--day ...]` | 生成中文日报 HTML + CSV 交易明细（+PDF 若可用）到 `reports_out/<day>/` |
| `bgwq tiers` | 查看七档本金配置与自动标记的问题 |
| `bgwq verify-assets --symbols SPCX` | 用官方 stockList/stockInfo 核对资产性质/发行商/合约（需密钥） |
| `bgwq serve` | 启动 FastAPI + 工作台，浏览 http://127.0.0.1:8000 （API 文档 /docs） |

全局参数：`--cost-profile token_dex|token_dex_optimistic|native_broker`、`--capital 10000`。

## 工作台页签

1. 行情排名：每日涨跌、振幅、成交额、代币收盘与基差（原生价与代币价分列）。
2. 复盘与交易：完整昨日 K 线、A 理论最优买卖点（蓝）、B 可执行信号点（绿买/红卖）、每笔买卖价格/成本/净盈亏、差距解释。
3. 回测/本金容量：walk-forward 样本外指标、基准对比、七档达标率、容量表（拆单/冲击/盈亏平衡/可验证性）、压力测试。
4. AI 信号：多周期 OOS AUC/Brier、置信区间、可靠性表、逐 bar 概率/期望收益/决策/解释与不交易理由。
5. 训练模式：隐藏未来 K 线，逐根推进，买/卖/观望，结束后对照 A 与 AI/规则并计分，记录成绩。
6. 日报：一键生成与下载历史报告。

## 管理员修改本金档位

编辑 `config/tiers.yaml` 或 `PUT /api/tiers`（body 同 YAML 结构）。系统会重新校验并把重叠/缺档/口径未知作为提示显示，不会自动修改数值。


## 执行安全（V1）

- 固定 `research_only`：不连接钱包、不请求私钥、不签名、不下单；`BGWQ_EXECUTION_MODE` 设为其他值会被强制回退并记录审计。
- 密钥只从本地 `.env`/环境变量读取，`.env` 已在 `.gitignore`。
- 未来 V2 真实交易接口需同时满足：显式授权、人工确认、单笔/日限额、紧急停机（`execution/guard.py` 已预留闸门，默认全部关闭）。
