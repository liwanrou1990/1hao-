# 05 · 网络与接口诊断（2026-10-21）

命令：`bgwq net-diag`（报告 `docs/net_diag_latest.json`）· `bgwq verify-matrix`（报告 `docs/asset_verification_latest.json`）

## 接口归属（不混用）
- 本系统使用 **Bitget Wallet ToB OpenAPI**：`https://bopenapi.bgwapi.io`，路径 `/bgw-pro/market/v3/rwa/*`（行情）与 `/bgw-pro/swapx/order/getSwapPrice`、`checkOrdersFee`（只读报价/费用）。签名 `x-api-key / x-api-timestamp(ms) / x-api-signature`。
- **不是** Bitget 交易所 API（`api.bitget.com`，ACCESS-KEY/ACCESS-SIGN/ACCESS-PASSPHRASE）。代码中没有任何交易所端点。
- 只读：绝不调用 `makeSwapOrder`、`submitSwapOrder` 或任何链上广播接口（单元测试断言）。

## 当前环境诊断结果
| 项目 | 结果 |
|---|---|
| DNS | 容器无外部域名解析（所有出网必须经代理 CONNECT） |
| 代理 | `HTTPS_PROXY` 已设；代理对 `bopenapi.bgwapi.io`、`web3.bitget.com`、`api.bitget.com`、`api.massive.com` 的 CONNECT 一律返回 403（策略拒绝） |
| TLS | 无法到达主机，未进入 TLS 阶段 |
| 时钟 | 本机毫秒时间戳可用（`date` 与 Python 相差 < 20 ms）；若服务端报时间戳过期需校时 |
| 签名 | 实现与官方 TS SDK 一致（Node 参考向量测试） |
| 限频 | 官方未公开；客户端对 429 报错，引擎按每分钟子单数（默认 10）限制 |
| 密钥 | 仅本地 `.env`；`call_log`/报告只记录布尔值，不含密钥 |

## 需要放行的域名（云环境 → Edit → Network access → Allowed domains）
| 域名 | 用途 | 级别 |
|---|---|---|
| `bopenapi.bgwapi.io` | 行情 + 只读可执行报价 | 必需 |
| `web3.bitget.com` | 官方文档 | 建议 |
| `api.massive.com` | 原生美股分钟线基准 | 可选 |

放行后依次运行：`bgwq net-diag`（应为“网络可达”）→ `bgwq live-test --symbols NVDA SPCX TSLA` → `bgwq verify-matrix` → `bgwq ingest --days 30 --periods 1m 5m 15m` → `bgwq matrix-report`。
只读可执行报价需额外配置 `BGW_QUOTE_ADDRESS`（查询用钱包地址，只读）与 `BGW_QUOTE_STABLE_CONTRACT`（计价稳定币合约）。
