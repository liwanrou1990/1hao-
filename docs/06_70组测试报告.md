## 逐项结论
1. **T5–T7（200 万–750 万美元）**：即使事后可执行上限（B）也无法达标。约束是盘口容量，不是策略：单根 K 线 10% 参与率约 1.1 万美元，5 根分批约 5.7 万美元；T7 本金超过全日预算。在当前流动性假设下**客观不可实现**，需真实盘口/池深度数据重新校准，或下调目标/延长周期。
2. **T3–T4（17.5 万–65 万美元）**：乐观成本下 B 部分可达（事后挑选），保守成本下不可达；C 为 0。瓶颈为成本门槛（往返成本 > 60 根波动 90 分位）与流动性共同作用。
3. **T1–T2（3 千–6 万美元）**：B 在两种成本下大多可达（事后），C 在 70 组中只有 3 组产生正净利润、无一达标：差距来自“不可预知”——因果引擎在训练窗内找不到稳定正期望参数，于是选择空仓（符合“无优势不交易”）。
4. **SPCX（7 组）**：资产身份与渠道未经 API 核实 → 标为“未验证”，未判定支持或不支持。
5. **做空/杠杆**：官方接口不提供；全部组合只做多。2 组在下跌趋势中记录“产品不支持做空”。
