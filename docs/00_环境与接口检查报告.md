## 3. 从官方 SDK 源码确认的接口规格

来源：`github.com/bitgetwallet/tob-api-sdk-ts`（Fern 生成）与 `github.com/bitgetwallet/tob-api-sdk`（Go）。

- Base URL：`https://bopenapi.bgwapi.io`
- 全部为 `POST`，JSON body：
  - `/bgw-pro/market/v3/rwa/stockList` body `{}` —— 返回所有 RWA ticker→合约映射（含已下线）。字段：`ticker, name, icon, status(online|offline), contracts[{chain, contract, symbol, data_source, status}]`
  - `/bgw-pro/market/v3/rwa/stockInfo` body `{ticker}` 或 `{chain, contract}`，可选 `has_offline`。返回 `ticker, name, latest_price, price_24h_change(_ratio), chain_assets[{chain, contract, symbol, decimals, latest_price, tx_maximum_buy_usd, tx_minimum_buy_usd, tx_maximum_sell_usd, tx_minimum_sell_usd, data_source(ondo|xstocks), market_status(open|close), market_status_code(regular|premarket|postmarket|overnight|paused|closed, ondo 专有)}]`
  - `/bgw-pro/market/v3/rwa/kline` body `{chain, contract, period?, size?, end_time?(秒)}`；period ∈ `1s 5s 15s 1m 5m 15m 30m 1h 2h 4h 6h 8h 12h 1d 3d 1w`，默认 `5m`；**ondo 不支持秒级与 12h**。返回 `list[{ts, open, high, low, close, volume?, amount?, txn?}]`，**ondo K 线不含 volume/amount/txn（为发行商报价而非链上成交）**。
  - `/bgw-pro/market/v3/rwa/transactionList` body `{chain, contract, side?(buy|sell), page?, size?(≤100)}`，返回 `{page, size, list[{side, tx_from, tx_hash, amount, price, value, ts}]}`
  - `/bgw-pro/market/v3/rwa/checkContractIsRwa` body `{chain, contract}` → `{is_existed, stock_ticker, data_source}`
- 签名：请求头 `x-api-key`、`x-api-timestamp`（毫秒）、`x-api-signature`；
  `payload = JSON(键排序,无空白){ "apiPath": path, "body": 原始body字符串, ...query, "x-api-key": key, "x-api-timestamp": ts }`，`signature = base64(HMAC-SHA256(secret, payload))`。
  已用 Node.js 按官方 TS 算法生成参考向量并在 `tests/test_phase1_data.py` 中校验 Python 实现一致。
- 错误：HTTP 400/403/429；业务层 `status=1` 时 `data` 为错误字符串。
- **发行商枚举只有 `ondo` / `xstocks`。"Reality" 未出现在官方枚举中**，系统将其列为"待确认发行商"，只有 `checkContractIsRwa`/`stockInfo` 返回时才标记。
- 社区 CLI（bitget-wallet-ai-lab/bitget-wallet-cli）使用的是另一套 v2 端点（`/market/v2/rwa/*`），非本项目依据。

## 4. SPCX 资产性质

- 公开资料：Ondo 发行 `SPCXon`（宣称 1:1 对应 SPCX 份额，Solana / Ethereum / BNB Chain）。
- **未验证**：本容器无法调用 `stockInfo(ticker="SPCX")` 核对 ticker、发行商、链与合约；也无法确认 Massive 是否提供 SPCX 原生分钟线。
- 处理：`config/symbols.yaml` 中 `SPCX.tradable=false, verification_required=true`，不纳入可交易策略；工作台与日报显示"待验证"。核对命令：`bgwq verify-assets --symbols SPCX`。

## 5. Massive 基准

- Polygon 兼容路由 `GET /v2/aggs/ticker/{ticker}/range/1/minute/{from}/{to}?adjusted=true&sort=asc&limit=50000`，Bearer 认证，`next_url` 分页。
- 套餐（公开资料）：Basic 免费、5 次/分、仅日终；Starter/Developer 15 分钟延迟、无调用上限；分钟级历史深度随套餐。`bgwq probe` 会实测两年前某日是否可取到分钟线以确认深度。
- 仅取常规时段 09:30–16:00（America/New_York），非交易日直接拒绝生成原生 K 线。

## 6. 阻塞清单（未伪造完成）

1. Bitget Wallet RWA 行情：无密钥 + 网络策略拒绝 → 权限/跨度/限频/成本未验证。
2. Massive：无密钥 + 网络策略拒绝 → 套餐与历史深度未验证。
3. SPCX：资产性质/发行商/合约未经官方接口核对 → 不可交易。
4. 代币真实成交成本（手续费、池深度、Gas）未知 → `config/costs.yaml` 为明确标注的假设，提供保守/乐观两档。
5. 本金档位：计息口径未知、档位重叠（50,000–99,999）、缺档（5,000–19,999）→ 原样标记，未补造规则。
