## 1. 网络与 API 复诊
| 检查项 | 结果 |
|---|---|
| DNS | 容器内无外部域名解析；所有出网必须经代理 CONNECT |
| 代理 CONNECT | `bopenapi.bgwapi.io`、`api.bitget.com`、`api.massive.com` 以及 Binance/Coinbase/Kraken/OKX/Bybit/CoinGecko 等 16 个公开行情域名全部 **403（网络策略拒绝）** |
| 白名单 | 需在云环境 **Network access → Allowed domains** 放行：`bopenapi.bgwapi.io`（必需）、`api.bitget.com`（加密货币公开 K 线，必需）、`web3.bitget.com`（文档，建议）、`api.massive.com`（可选） |
| 鉴权/签名 | Bitget Wallet ToB OpenAPI：`x-api-key / x-api-timestamp / x-api-signature=base64(HMAC-SHA256(secret, sortedJSON))`，实现与官方 TS SDK 参考向量一致（单元测试）；交易所 API（ACCESS-KEY/PASSPHRASE）与本系统无关 |
| 时钟 | 本机毫秒时间戳正常；若服务端报时间戳过期需 NTP 校时 |
| 结论 | **当前环境无法到达任何真实行情源**；所有回测结果仍为 SIMULATED，报告中逐处标注 |

## 3. 密钥审计（`docs/key_audit_latest.json`）
- `.env` 存在且在 `.gitignore`；当前 Key/Secret 及两枚历史 Secret **均未出现在**任何已跟踪文件、git 历史（`git log -S`）、docs/reports_out/logs/src/config/tests 扫描中。
- **轮换要求**：API Secret 曾以明文出现在对话渠道，该渠道不受仓库控制 → 应在 Bitget Wallet 控制台重置 Secret（必要时同时重置 Key），只更新本地 `.env`，不要再粘贴到聊天。审计报告只记录 SHA-256 前 12 位指纹。
- **未知 32 位十六进制值**：长度 32、纯小写十六进制；与本地 Key/Secret 的 MD5 / SHA-1 / SHA-256 截断均无关系；格式不符合 `x-api-key`（16 位）或 Secret（40 位）；不是 Bitget 交易所 Key（`bg_` 前缀）或 Secret（64 位）；不是 Massive Key（含字母大小写）。**最可能是 Bitget Wallet 控制台中的商户/项目标识（appId / projectId），不参与签名，本系统任何接口都不需要它。** 在确认用途前不存储、不写入 `.env`。

## 4. 执行安全（不变）
`BGWQ_EXECUTION_MODE=research_only`；代码中不存在 `makeSwapOrder`/`submitSwapOrder`/任何签名广播或资金转移调用（单元测试断言）；加密货币客户端只有公开行情读取。
