## 4. 实时参考价 vs 最新完整日线

- 参考价：聚合即时价（Bitget ticker → DefiLlama → CoinGecko），带价格时间戳（UTC 与北京时间同时显示）与延迟秒数；超过 30 分钟标“延迟”，全部失败标“不可用”并回退显示最后日线收盘且标签改为“最后日线收盘（延迟）”。
- 日线：UTC 自然日 K 线，昨日已收盘 = 延迟 0 天；所有均线、风险评分、成交概率均基于日线收盘计算，与参考价口径不同，页面明确分列。
- 快照过期：生成时间超过 30 小时时页顶红色横幅“快照已过期”，所有价格标为过期数据。已用人为 40 小时前的快照实测（截图 `docs/spot90_validation/phase4/dashboard_stale_demo.png`）：过期横幅、数据延迟警告、“最后日线收盘”标签均正确出现。

## 5. 14 天限价成交模型最终审计

- 样本：57,312 行 = 2388 个决策日 × 2 币种 × 12 档折价；行与行高度重叠（同日 12 档共用一条价格路径，相邻日 14 天窗口重叠 13 天）→ 有效独立样本约为 100 个 24 天块，统计误差按块自助给出。
- 逻辑回归样本外：AUC 0.784（95% CI 0.768~0.799），Brier 0.188（0.182~0.195），ECE 0.046（0.034~0.067）。
- **关键发现**：与“按折价档的历史成交率”这一朴素基准相比（AUC 0.784、Brier 0.189、ECE 0.057），Brier 技能仅 +0.003（CI -0.032~+0.029，跨 0）。合并 AUC 0.78 几乎全部来自折价深度本身；在同一折价档内，模型的排序能力只有 AUC 0.54~0.60（波动率高时更容易成交）。
- 分年份（AUC / ECE / 校准偏差=预测−真实）：2020 0.81 / 0.17 / +0.16；2021 0.77 / 0.05 / -0.05；2022 0.76 / 0.07 / -0.07；2023 0.83 / 0.12 / +0.10；2024 0.79 / 0.04 / -0.00；2025 0.78 / 0.04 / -0.02；2026 0.78 / 0.06 / -0.04。2020 年高估 16 个百分点（训练样本少且 2020-03 极端波动），2023 年高估 10 个百分点，其余年份偏差 ≤ 7 个百分点。
- 分趋势状态 AUC 0.75~0.80、ECE 0.04~0.07，无系统性失效。
- 结论：保留该模型作为“挂单能否成交”的校准良好的参考工具，页面同时显示历史成交后 90 天盈利率（56%~60%，与立即买入无异）以防止把成交概率当盈利概率；它的信息量有限，不应作为任何决策的核心依据。

## 6. 三方案比较口径审计

- 同一起始资金（10,000 USDT）、同一决策日期集合、同一手续费（10 bps/边）与滑点（市价 5 bps，限价 0）、同一现金收益假设：由测试 `test_plans_same_capital_dates_fees` 自动验证（一次性买入结果不随等待参数变化；常数价格下三方案净值完全相同 = 双边费用 15 bps）。
- **性质**：独立滚动模拟——每个历史起始日各自开一个假想账户、窗口末平仓；**不是**一个连续资金账户的可执行净值曲线，不同起始日之间资金不滚存，也不考虑同时持有多笔的资金占用。页面与快照均已注明。
- 结果要点（BTC 90 天，2868 个起始日）：一次性 +16.0% / 回撤 −27.3%，定投 +12.5% / −23.7%（差值 CI [−7.8%, −0.3%]），等待 3% +14.3% / −26.7%，等待 5% 持币 +5.9% / −16.0%；收益/回撤比三者相近（0.53~0.59）。

## 8. 已知风险与限制

1. 本环境 Bitget 不可达：日线为 Binance 现货、参考价为 CoinGecko 聚合；在能访问 api.bitget.com 的机器上会自动切换为 Bitget 数据（代码路径已测试，但未在真实 Bitget 响应上验证 V3 interval 枚举，首次运行请看 data_status 的 attempts）。
2. 备用源每日 03:17 UTC 更新，最新完整日线通常滞后到前一 UTC 日；若 GitHub 不可达则日线停更并触发 WARN/FAIL。
3. 参考价来自第三方聚合，分钟级延迟，可能与 Bitget 盘口差万分之几；页面只把它当参考价。
4. 风险评分与趋势状态是固定规则，不是预测；三阶段验证显示它们对 90 天结果几乎无区分力。
5. 成交概率模型信息量有限（见第 5 节）。
6. 方案比较为独立滚动模拟，不是可执行的连续账户。
7. 告警依赖 cron 退出码 / alerts.log / 可选 webhook；没有进程级守护，Streamlit 需用 systemd/supervisor 或 `nohup` 常驻（8 轮页面测试内存无增长）。
8. 链上数据（Coin Metrics 归档止于 2026-05-23）未纳入监测页面。
