## 0. 十个问题的直接回答

| 问题 | 回答 |
|---|---|
| A. 什么价格结构下最值得买入？ | 历史上能通过全部预登记门槛（周线 UP + 日线 SMA200 上行 + 回调到已确认支撑区并缩量后确认，或突破已确认阻力后回踩企稳 + 上方有 ≥1.5R 的已确认阻力作为 T1）的机会 **8.8 年只有 5 次**（ETH 4 次、BTC 1 次），全部出现在 2019-05、2020-07、2020-09、2023-06、2024-12 的趋势中段。183 个 A/B 候选中 176 个被拒，原因几乎只有一个：**上方没有已确认的阻力结构可作为 ≥1.5R 的第一目标**——即候选大多出现在创新高阶段。结论：按“目标必须来自已知阻力”的纪律，最值得买入的是“上涨趋势中回调到已确认支撑区、且上方仍有历史阻力可作目标”的位置；这种位置稀少。 |
| B. 如何确认买盘而不盲目抄底？ | 预登记用的代理：回调期间出现缩量下跌日（卖压减弱）+ 确认日收盘高于区域上沿与昨高、收盘位于当日振幅上 40%、量比 ≥ 0.8；突破回踩要求收盘突破 → 回踩区域上沿 ±0.5 ATR → 收盘高于回踩日高点。**没有真实逐笔 / 订单流数据**（覆盖范围 0 条），主动买盘、订单流差额、吸收能力无法研究，本阶段没有合成任何订单流；上述代理在样本内没有产生可统计的优势（见 §3）。 |
| C. 在哪里卖出，什么情况下继续持有？ | 事前 T1 = 入场上方最近且 ≥1.5R 的已确认阻力区下沿；T2 = 再上一个阻力区或测量目标；失效价 = 区域下沿 −0.5 ATR 与最近已确认摆动低点 −0.25 ATR 的较高者。三种退出中，**退出 C（结构失效 + 3 ATR 跟踪、不设固定目标）是唯一在 25 bps 下为正的版本**（V2 +350、V4 +213），退出 A/B 为负（−75 至 −225）：有限的几笔盈利交易都是靠“继续持有让趋势跑”，而不是在 T1 兑现。 |
| D. 相比原 Brando 模型，净收益改善多少？ | **没有改善，而是大幅落后。** 全样本 25 bps：Phase 10 的 S1 BTC SMA200 +54,181、B2 状态机 +54,324、S2 +69,849；Phase 11 最好的核心配置 V2 退出 C +350，主配置 V4 退出 B **−168**。 |
| E. 最大回撤是否明显降低？ | 是，但代价是几乎不持仓：Phase 11 全部配置最大回撤 **−2% 至 −6%**（Phase 10 为 −25% 至 −79%），因为 94–99% 的时间空仓、平均仓位 0.1–0.4%。这不是风险管理的胜利，而是系统基本不交易。 |
| F. 是否优于 BTC/ETH 直接买入持有？ | **否**。全样本 BTC 买入持有 +46,364、ETH +19,503；Phase 11 任何配置都在 ±500 USDT 内。只在 2022–2023 熊市段“优于”买入持有（≈0 vs −1,183 / −3,966），与持有现金等价。 |
| G. 哪些市场阶段模型失效？ | 全部阶段都不产生足够交易：熊市 / 震荡（周线非 UP）被前置过滤排除（正确地空仓）；牛市创新高阶段被“必须有已知阻力目标”排除（错误地空仓）。模型只在“趋势中段仍有上方历史阻力”的狭窄窗口工作，2021、2022、2025、2026 全年零成交。 |
| H. 结果是否依赖少数异常大交易？ | 是（无法避免）：每个配置闭合交易 2–6 笔，最大 5 笔占比 100%；唯一像样的盈利是 2020-07 ETH 回调买入（退出 C 下 +554 USDT，持有 59 天）。样本量不足以做任何统计推断。 |
| I. 有没有足够证据进入未来 90 天前瞻？ | **没有。** 预登记判定三条（优于原模型、优于买入持有、不依赖最大 5 笔）全部不成立；系统每年 0–2 个信号，90 天前瞻预期 0–1 笔交易，不可能产生证据。不建议新开前瞻账户。 |
| J. 没有稳健优势，下一步改进什么？ | 见 §7：① 问题不在“识别买点”而在“目标必须来自已知阻力”与“1% 风险 ÷ 10% 止损距离 = 10% 仓位”两条规则把趋势系统的收益来源（创新高后的长持仓、满仓参与）砍掉了；② 真正值得做的是对已有的 SMA200 / 状态机系统做“回调分批建仓 + 结构止损”的叠加研究，而不是另起一套低频价格行为系统；③ 任何改动都要先预登记、再用未来前瞻数据验证，不能再在 2018–2026 上反复试。 |

## 1. Phase 10 结果独立复核（`phase10_audit.md`）

- 日线：BTC/ETH 各 3,370 根 = 2017-08-17 → 2026-11-07 的日历天数（相等），无重复、OHLC 合法、无其他资产；其中 137 根为 2017 年预热（仅用于 SMA200），研究窗口 2018-01-01 起 3,233 根。现货，无复权。
- 成本口径：25 bps = **单侧**（买 25 + 卖 25 = 往返 50），从成交记录核实：买入成交价 = 参考 × 1.0005，手续费 = 成交额 × 0.2%。
- 无未来函数抽样：S1 在截断到 2021-12-31 的数据上重跑，与全量数据下同期 32 笔成交与净值逐项一致。
- 收益来源：S1 闭合交易净额 48,953，最大两笔 53,673（110%），去掉最大五笔后 **−30,210**；S2 最大两笔 79%，去掉五笔 −26,254；只有 B2 状态机去掉五笔仍 +23,891。全部核心策略只在牛市月盈利。
- 原策略 vs 买入持有：全样本 S1 +7,817、S2 +23,485 超过 BTC 持有；2024–2026 全部落后 BTC 持有（−1.5k 至 −4.1k）；**没有任何策略在训练 / 验证 / 测试三段都战胜 BTC 持有**。
- 最大回撤 −65%（S1）/ −74%（S2）/ −25.5%（B2），最长回撤期 702–1,054 日，期末净值 64,341 / 80,049 / 64,402，均与报告一致。
- 选择偏差：2018–2026 已被 Phase 4–10 反复查看，2024–2026 段不是盲测；BTC/ETH 为事后存活币种。Phase 11 全部窗口沿用同一声明。

## 2. 方法（预登记摘要）

- 数据：同 Phase 10 副本；周线由日线重采样，只用已收盘周。订单流：无；宏观事件：FOMC 决议日为已知日程，CPI / 非农按 BLS 常规规则生成并标注 `approx=True` 未逐条核验；日粒度过滤（1h 数据仅 2022 起，15/30/60 分钟窗口不可支持）。
- 结构：分形摆动点日线 k=3、周线 k=2，确认滞后；周线趋势 = HH+HL+周收盘 > SMA30 周；日线 SMA200 上行过滤；支撑阻力区 = 已确认摆动点聚类（0.5 ATR）外扩 0.25 ATR；强度 = 触碰数。
- 入场 A 回调确认 / B 突破回踩 / C 假跌破（实验组）；事前 T1/T2/失效价/净盈亏比 ≥ 1.5（C 2.0）/ 仓位（0.5%/1% 风险，50/70/100% 配置，联合风险 1.5×，回撤约束 20/30/40%，高波动减半）；退出 A/B/C；成本 0/15/25 单侧；窗口训练 2018–21 / 验证 2022–23 / 历史测试 2024–26（已查看）/ 全样本 + 逐年。
- 执行：收盘决策、次日开盘成交，T1/T2 为入场时挂出的限价单（当日最高触及按目标价成交，开盘跳空按开盘价），止损按收盘判定次日开盘成交，跳空低于止损按开盘价。

## 4. 风险与回撤（问题 E / 六）

所有 Phase 11 配置的最大回撤 ≤ 6.2%、最长回撤期最长 2,720 日（从 2020 的小亏开始长期未创新高）。回撤低完全是因为不持仓：V4 退出 B 平均仓位 0.3%，资金使用效率（清仓净收益 ÷ 平均仓位）为负。20/30/40% 回撤约束、50/70/100% 配置上限在整个样本内从未被触发，因此无法评估它们对收益 / 回撤的权衡；这一点如实记录，不得把“回撤 ≤ 6%”当成系统的风险控制能力。

## 5. 宏观事件过滤（七）

事件表：FOMC 71 个决议日（2018–2026，含 2020-03 两次紧急会议）、CPI 与非农各 108 个按规则生成的日期（`approx=True`）。日粒度 pre_event / post_event 与无过滤相比，全样本 25 bps 下差异 −60 vs −168（退出 B）、+319 vs +213（退出 C），仅由个别信号恰在事件日被推迟造成，样本不支持任何结论。15/30/60 分钟确认窗口因数据频率（1h 仅 2022 起、15m 仅 2024-12 起）**未实施**。

## 6. 数据局限与未完成项（如实列出）

- 无逐笔成交 / 订单流数据：主动买盘、订单流差额、价格吸收能力**未研究**；未合成任何替代数据。
- CPI / 非农首次公布时间戳未逐条核验（规则近似）；FOMC 日程为已知日历，未附官方抓取（网络白名单不含 Fed/BLS）。
- 分钟级事件确认窗口未实施。
- 2024–2026 段已被 Phase 10 查看，不是盲测；真正的样本外只能来自后续前瞻。
- 样本量：核心配置闭合交易 2–6 笔，任何收益 / 胜率 / 盈亏比数字都没有统计意义。
- 滑点固定 5 bps、无流动性冲击模型（10,000 USDT 规模下合理）。

## 7. 诊断与下一步建议（不是新结论，是待预登记的假设）

1. **规则冲突**：预登记要求 T1 来自已确认阻力且 ≥1.5R。趋势系统的收益来自创新高后的长持仓，而创新高时没有上方阻力，于是 96% 的候选被拒。若要保留“事前目标”纪律，T2/T1 需要允许“测量目标”作为主目标（本阶段仅作 T2 后备），这是一个需要预登记的规则改动。
2. **仓位规则**：1% 风险 ÷ 约 10% 止损距离 ≈ 10% 仓位，即使全部交易盈利也无法接近买入持有；Phase 10 的 SMA200 系统 50% 时间满仓才拿到 +54k。风险预算型仓位与“最终 USDT 最大化”目标在这里是矛盾的。
3. **更有希望的方向**：以已验证的 SMA200 / 状态机为主干（满仓参与趋势），用本阶段的结构模块只做两件事——① 回调到已确认支撑区时分批加回仓位（而不是作为唯一入场）；② 用结构失效 / 3 ATR 跟踪替代 SMA200 单一退出以减少 2021-H2、2024-H2 式的来回止损。这需要新的预登记，并且只能用 2026-11 之后的前瞻数据作为真正样本外。
4. **不建议**：为了让本阶段的 PA 系统出成绩去放宽 RR 门槛、放大仓位或改确认条件——那是在同一份历史上做第 N 次拟合。
5. 现有 Mac 三个前瞻账户继续运行；本阶段不新增任何前瞻账户或影子信号写入。
