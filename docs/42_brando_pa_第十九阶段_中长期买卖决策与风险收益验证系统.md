## 1. 市场状态与候选买点

周线七类状态（只用已完成周线与已确认摆动点；截断历史重算结果完全一致，测试断言），2014 年以来周数占比：长期上涨 27%、底部构筑 23%、突破回踩 19%、长期下跌 14%、正常回调 11%、震荡 6%。

候选买点（候选 ≠ 买入信号）：A 趋势回调 110 个（2015-11 → 2025-11），B 突破回踩 12 个（2015-12 → 2024-03），C 熊市后趋势恢复 3 个（2015-07、2019-04、2023-01）。每个候选都有入场区间、结构依据、成交量依据（**价格行为确认，尚无真实订单流确认**）、失效价、潜在最大损失、两个目标区、扣费后风险收益比与确认状态（见 `phase19_results.json` 的 candidates）。

预登记要求扣费后风险收益比 ≥ 1.5 才采用：A 只有 39% 通过、B 58%，**C 三次都不通过**（失效价设在周线摆动低点，离入场太远），所以 C 类策略在整个历史中一次都没有买入。

全部 16 个方案判定“不采用”。共同原因：验证段与重复检验段都没有超过买入持有，风险调整条件也不满足；训练段大多低于原 SMA200；牛熊环境条件不满足；多数方案全样本闭合交易 < 10。
